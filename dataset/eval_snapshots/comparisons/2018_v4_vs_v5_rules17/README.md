# 2018：v4 与 v5-rules17 的 Judge / GB 对照

## 结论

新版 Prompt 产生的五维分数对 GB **明显比 v4 更有效**，但新版 Judge 直接总分没有改善，
反而更偏高。因此当前正确解读是：新版五维中已经出现可供 GB 学习的有效信号，但总分生成
与跨批次泛化仍需继续验证。

## 数据质量

- 同一批 22 位教师；标签均为同一份专家分数。
- v4 读取冻结快照 `dataset/eval_snapshots/v4/2018_spring/`。
- v5 读取 `dataset/2018_spring/cache_fixed_prompt/`，22 份均为 `v5-rules17`、同一
  `judge_fingerprint=d2ab51e19bef6919`，无网络错误兜底分。
- 三份曾发生网络错误的评分已补跑；原异常 JSON 以 `scores.network_error.json` 保留审计。

## 主结果（0–5 分）

所有 GB 结果均为留一交叉验证：预测每位教师时，只使用另外 21 位训练。特征为五维分数，
模型参数与项目现有 GB 回归器一致。

| 方法 | MAE | RMSE | Spearman | 说明 |
|---|---:|---:|---:|---|
| 留一训练均值基线 | 0.911 | 1.153 | -1.000 | 不使用五维；仅作误差基线，留一均值与标签天然反向 |
| v4 Judge 直接总分 | 1.183 | 1.549 | 0.081 | 未训练 GB |
| v5 Judge 直接总分 | 1.297 | 1.660 | 0.173 | MAE 比 v4 变差 0.113，整体仍明显偏高 |
| v4 五维 → GB | 1.398 | 1.659 | -0.245 | 未学到可泛化关系 |
| v5 五维 → GB | **0.825** | **1.015** | **0.528** | MAE 比 v4 降低 0.573（约 41%） |

0–5 分 MAE 乘以 0.4 可换回专家原始 2–4 分量纲：v4 GB 约为 0.559 分，v5 GB 约为
0.330 分，训练均值基线约为 0.364 分。

配对误差 bootstrap 中，v5 GB 相对 v4 的 MAE 改变量 95% 区间为
`[-0.987, -0.168]`，20,000 次抽样中 99.78% 为 v5 更好。该区间只描述这 22 人上的
配对稳定性，不能替代跨年份外部验证。

## 缺失维度消融

新版的教学效果只有 5/22 可观察。为排除 GB 利用“有无学生或视频形式”形成假规律，完全
删除教学效果后重新验证：

| v5 设置 | 留一 MAE | 50 次重复 5 折平均 MAE |
|---|---:|---:|
| 五维 + 缺失指示器 | 0.825 | 0.885 |
| 五维，仅中位数填补 | **0.802** | 0.876 |
| 删除教学效果，只用四维 | 0.834 | **0.874** |
| v4 五维 | 1.398 | 1.381 |
| 训练均值基线 | 0.911 | 0.917 |

删除教学效果后，新版在 50 次相同的重复 5 折划分中 50/50 优于 v4，并有 68% 的划分优于
训练均值基线。教学效果是否可观察与专家分的相关仅为 -0.064，说明本次提升不是主要依靠
视频形式缺失。

## 参数敏感性

使用四个稳定维度，在 `n_estimators = 50/100/200`、`max_depth = 1/2/3` 的 9 种组合中，
v5 在留一和重复 5 折下全部优于 v4。不能根据同一批 22 人选择其中最优参数，否则会产生
调参偏差；正式参数应由新增年份或预先固定的验证集决定。

## 解释与下一步

1. 新规则改善了五维的联合结构，GB 已能提取部分专家总分信号；这支持继续保留
   “LLM 五维诊断 → GB 校准总分”的路线。
2. v5 Judge 直接总分均值为 3.963，专家标签均值为 2.705，仍存在明显高估。不能把 Judge
   自报总分作为最终分数，也不能据此宣称 Prompt 已经整体准确。
3. v5 GB 对训练均值基线的优势较小（留一 MAE 仅低 0.086；重复 5 折平均低约 0.043），
   22 人仍不足以确认稳定泛化。
4. 下一步应冻结本版规则与 GB 参数，在未参与规则生成或调参的 2019/2022/2024 数据上做
   真正的外部验证；若仍优于 v4 和训练均值基线，再决定用于线上总分。

## 产物

- `predictions.csv`：22 人逐人的专家分、v4/v5 Judge 与留一 GB 预测及误差变化。
- `score_distributions.csv`：五维和总分分布。
- `robustness.json`：缺失维度消融、重复 5 折与相关性。
- `dimension_correlations.csv`：每一维与专家总分的相关性。
- `hyperparameter_sensitivity.csv`：9 组浅树参数敏感性。
