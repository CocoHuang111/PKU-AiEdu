# Judge v4 评估快照

本目录保存启用专家蒸馏规则前的评估数据，用于与后续版本逐样本对照。

- `global/`：重评前的全量汇总、GB 训练与预测文件，以及旧版冻结经验（如存在）。
- `2018_spring/`：2018 批次的汇总表和 22 份 `scores.json`。
- 原始视频、转写、客观特征及其他大体积缓存未复制；它们仍保留在原数据目录。
- 快照中的评分由 `prompt_version=v4` 生成，旧文件尚未记录 Judge 指纹。

创建此快照后，仅重评 `dataset/2018_spring/`；在其他年份完成同版本重评前，不更新全量合并表，以免混用评分版本。
