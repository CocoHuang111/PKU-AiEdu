# 网盘视频导入（开发中，尚未部署）

分支：`codex/cloud-drive-video-import`。保留原有视频直链、浏览器快速上传和分片上传。
用户在链接入口粘贴分享链接或含提取码的分享文本，点击“读取链接”，进入目录并选择视频后开始导入。
同一请求只导入一个视频；不批量转存文件夹。文件 ID 必须来自该分享当前目录，下载时重新校验。

## 管理员配置

仅在服务端的本地 `.env` 或部署环境文件配置下列值，切勿提交 Git、打印日志或发送到聊天：

```dotenv
BAIDU_NETDISK_COOKIE=
QUARK_NETDISK_COOKIE=
QUARK_IMPORT_FOLDER_ID=
```

使用专用导入账号，不建议使用个人主账号。配置 Cookie 代表授权系统使用该账号的正常下载权限。
Cookie 会过期，过期或遇验证码后需要管理员在网盘完成合法验证，再更新环境配置并重启服务。
百度未配置账号时可尝试读取分享，但实际下载会提示缺少配置，不会悄悄降级成无效网页下载。

夸克需同时配置 Cookie 和专用目录 ID，不能仅配置 Cookie 后写入默认根目录。
**导入会把选中的视频转存到该目录，副本保留在网盘中。** 页面在导入前说明这一行为；
当前不自动删除网盘文件、不清空回收站，也不操作分享内其他文件。
管理员需管理该目录的容量，重试可能产生重复副本。这是当前限制，不是断点转存实现。

Google Drive 当前使用公开分享，不读浏览器登录信息，不接受用户上传 Google Cookie。
应允许“知道链接的人”查看并允许下载。服务器网络必须能连接 Google；不自动更改代理或网络策略。

## 安全与资源限制

- 元数据响应最多 4MiB、最多 100 次适配请求、目录路径最多 12 层；百度/夸克分页有上限，超限明确提示。
- 解析与下载分别有超时；下载保留原有大小、磁盘余量、视频时长与 ffprobe 校验，以及失败清理。
- URL 与每次重定向检查协议、域名解析、私有 IP 和端口；原直链仍仅允许 80/443。
- 北大适配器单独允许已验证的 `https://diskasu.pku.edu.cn:10002` 对象存储源，不允许任意非标准端口。
- API Bearer 凭证不传给下载服务器；账号 Cookie 限定固定提供方 API 或下载源，跨源重定向不携带。
- 页面仅收到文件名、文件 ID、大小和目录标志，不暴露签名地址、分享令牌和管理员 Cookie。
- 不记录或持久化分享原文、密码和临时下载 URL；选择信息仅在本次页面内存和请求中使用。
- 继承的公网 DNS 检查还不是固定 IP 连接机制，DNS 重绑定防护需在后续安全加固和部署出口策略中补齐。
