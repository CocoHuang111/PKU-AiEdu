# 学习分析伦理与数据治理

> DELICATE、SHEILA 框架及高校 AI/学习分析最低治理要求。

**文献性质**：学习分析伦理经典框架 + 高校政策形成研究  
**核心出处**：Drachsler & Greller (2016)；Tsai et al. (2018) SHEILA；UNESCO AI Ethics Recommendation  
**整理说明**：DELICATE 与 SHEILA 步骤据原文；治理清单为高校应用归纳。  
**核实日期**：2026-08-06

---

## 来源标注说明

DELICATE 见 Drachsler & Greller [1]；SHEILA 见 Tsai et al. [2]。

## 核心问题

学习分析（Learning Analytics, LA）与 AI 驱动的学情系统常收集：LMS 点击、作业时长、论坛参与、预测风险分数等。

伦理问题不仅是「能否收集」，还包括 [1][2]：

- 目的是否**正当**？
- 是否**必要**且**比例适当**？
- 能否真正**改善学习**？
- **谁承担误判后果**？

## DELICATE 清单

Drachsler & Greller (2016) 提出 DELICATE [1]：

| 字母 | 议题 |
| --- | --- |
| **D**etermine plan | 明确分析目的与问题 |
| **E**xplain | 向利益相关方解释 |
| **L**egality | 合法性（GDPR、个人信息保护法等） |
| **I**nvolve stakeholders | 参与式设计 |
| **C**onsent | 知情同意 |
| **A**nonymize | 匿名化（注意再识别风险） |
| **T**echnology & security | 技术安全 |
| **E**xternal partners | 第三方数据处理 |

## SHEILA 框架（机构政策形成）

Tsai 等 (2018) 的 SHEILA 面向**高校机构**制定 LA 政策 [2]，基于欧洲 16 国 51 所高校访谈：

1. **S**tate of play：现有数据环境与能力
2. **H**eart of stakeholders：识别利益相关方与关切
3. **E**ngage in dialogue：对话形成价值共识
4. **I**dentify desired behaviour change：希望改变什么教学行为
5. **L**earn from experience：试点与迭代
6. **A**ct：发布政策与治理结构

## AI + LA 的叠加风险

| 风险 | 说明 |
| --- | --- |
| **预测标签** | 「辍学风险」可能固化不平等、诱发自证预言 |
| **相关性≠因果** | 点击多 ≠ 学习好 |
| **黑箱模型** | 学生不知为何被标记 |
| **数据连接再识别** | 「匿名」数据集仍可能被 deanonymize |
| **功能蔓延** | 为教学收集的数据用于disciplinary |

## 最低治理要求（高校 checklist）

| 领域 | 要求 |
| --- | --- |
| **数据最小化** | 只收集达成目的所需数据 |
| **目的限制** | 新用途需重新告知/同意 |
| **访问控制** | 角色分级；审计日志 |
| **保留期限** | 到期删除或归档 |
| **模型验证** | 偏差审计、定期复测 |
| **解释与申诉** | 学生可质疑 automated 决策 |
| **退出机制** | 在可能范围内 opt-out |
| **第三方合同** | 明确数据归属与删除义务 |

## 与中国法规的衔接

- 《个人信息保护法》强调告知同意、最小必要、敏感个人信息保护。
- 教育部《「人工智能+教育」行动计划》要求安全审核、备案与风险响应 [3]。
- 清华 AI 教育原则：**严禁**用敏感/涉密/未授权数据训练或驱动 AI [4]。

## 教学场景边界

- **课堂 AI 工具**若上传学生作业到境外服务器——属数据治理问题，非仅 integrity 问题。
- **AI 批阅**若产生持久学生 profile——需 LA 伦理审查。
- 透明 dashboard 若**不可理解**——不等于 ethical；需 plain language 说明。

## 边界与风险

- 伦理框架多，**长期实证**仍有限 [2]。
- 单次 broad consent 难以覆盖用途变化。
- 教师个人使用 ChatGPT 分析学情**也可能违规**——若含 identifiable student work。
