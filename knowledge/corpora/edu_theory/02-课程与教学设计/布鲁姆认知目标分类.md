## 来源标注说明

六层次与四知识类型见 Anderson & Krathwohl (2001) 第 1–2 章。

## 认知过程维度（由低到高）

| 层次 | 定义 | 典型行为动词 | 大学课程示例 |
| --- | --- | --- | --- |
| **记忆（Remember）** | 从长时记忆中提取相关知识 | 列举、识别、描述、命名 | 列出机器学习主要算法类别 |
| **理解（Understand）** | 从 instructional messages 中构建意义 | 解释、归纳、举例、分类、比较 | 用自己的话解释过拟合的含义 |
| **应用（Apply）** | 在给定情境中执行或使用程序 | 执行、实施、计算、演示 | 对给定数据集运行分类流程 |
| **分析（Analyze）** | 将材料分解为组成部分并确定关系 | 区分、组织、归因、比较 | 比较两种方法的假设与适用条件 |
| **评价（Evaluate）** | 基于标准和准则做出判断 | 检验、批评、判断、辩护 | 评价某篇论文的方法论缺陷 |
| **创造（Create）** | 将要素组合成新的连贯整体 | 设计、构建、规划、生成 | 设计一个针对特定问题的实验方案 |

## 知识维度

修订版增加了知识类型区分，避免「只会做不会想」：

| 类型 | 说明 | 示例 |
| --- | --- | --- |
| **事实性知识（Factual）** | 孤立的基础元素 | 术语、具体细节、元素 |
| **概念性知识（Conceptual）** | 更复杂的、有组织的知识 | 分类、原理、理论、模型 |
| **程序性知识（Procedural）** | 如何做某事 | 算法、技巧、方法、准则 |
| **元认知知识（Metacognitive）** | 关于认知的知识 | 策略知识、自我知识、任务知识 |

**完整目标表述** = 认知过程 × 知识类型。例如：「**分析**（过程）**概念性知识**（类型）：比较监督学习与非监督学习的核心假设。」

## 撰写课程目标的常见误区

### 1. 目标层次偏低

大量目标停留在「记忆」和「理解」——「了解 XX 的发展历史」「理解 XX 的基本概念」。高年级课程和研究生课程应有明确的「分析」「评价」「创造」层次目标。

### 2. 动词模糊

「掌握」「熟悉」「了解」无法观测、无法评价。应替换为可观测的行为动词。

### 3. 目标与考核脱节

目标写「能够设计实验方案」，期末只有选择题——典型的目标—评价错配。

### 4. 只写教师行为

「介绍机器学习基本方法」描述的是**教师**做什么。应写**学生**能做什么：「学生能够针对给定问题选择合适的机器学习方法并说明理由。」

## 目标—活动—评价对齐示例

**目标（创造层）**：学生能够设计一份完整的课程大纲，含目标、内容、活动与评价方案。

| 对齐要素 | 设计 |
| --- | --- |
| 教学活动 | 分析 3 份范例大纲 → 小组讨论评价标准 → 分阶段撰写 |
| 评价方式 | Rubric 评价 + 同行互评 + 教师反馈 |
| 支撑性目标 | 分析层：能识别范例大纲的优缺点；评价层：能依据 rubric 给出有依据的判断 |

## 不同课程类型的目标层次建议

| 课程类型 | 建议覆盖的最低层次 | 说明 |
| --- | --- | --- |
| 低年级通识/概论 | 理解 + 应用 | 建立概念框架和基本技能 |
| 专业核心课 | 应用 + 分析 | 能运用原理解决学科问题 |
| 高年级研讨/项目 | 分析 + 评价 + 创造 | 独立研究和批判性判断 |
| 研究生课 | 评价 + 创造为主 | 产出原创性工作 |
