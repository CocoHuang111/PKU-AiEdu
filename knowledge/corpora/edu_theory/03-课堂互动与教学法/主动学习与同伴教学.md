## 什么是主动学习

**主动学习（Active Learning）** 指学生参与学习过程、而不仅是 passively 接收信息。Freeman et al. (2014) 的操作性定义：「任何迫使学生 during class 做 something besides listening、做 something besides reading、做 something besides taking notes 的活动。」

包括但不限于：讨论、投票、问题解决、peer teaching、案例研讨、即时练习。

## 证据基础

Freeman et al. (2014, *PNAS*) meta-analysis 主要发现：

| 指标 | 主动学习 vs 传统讲授 |
| --- | --- |
| 考试成绩 | 平均提高约 **0.47 个标准差**（约 6 个百分点） |
| 挂科率 | 传统讲授班挂科率 **1.95 倍**于主动学习班 |
| 概念 inventory | 主动学习效果**更大**（说明深层理解改善更多） |
| 班级规模 | 各规模均有效，**小班（≤50）效果最大** |
| 学科 | 所有 STEM 子领域一致 |

**结论**：在本科 STEM 教育中，主动学习应作为默认实践，传统讲授作为对照组需重新 justification。

## 同伴教学（Peer Instruction）

Eric Mazur（Harvard）1991 年开发的结构化主动学习法，特别适合大班讲授型课程向互动转型。

### 标准流程

1. **短讲授**：5–10 分钟，聚焦一个核心概念。
2. **概念测试（ConcepTest）**：一道选择题，针对常见误解，非简单记忆。
3. **独立思考**：1–2 分钟，学生 individual 作答。
4. **同伴讨论**：2–4 分钟，邻座学生互相说服对方。
5. **再次投票**：看分布是否变化。
6. **教师讲解**：根据投票结果针对性解释，然后进入下一概念。

### ConcepTest 设计原则（Mazur）

- 聚焦**一个**重要概念，对应常见学生困难。
- 需要** genuine thought**，不是套公式。
- 只有一个正确答案，但干扰项应** plausible**（反映典型误解）。
- 表述清晰直接。
- 难度适中——约 40–70% 第一次答对为宜。

### 为什么有效

- **全体参与**：不同于「谁举手谁答」，每个学生在每个 ConcepTest 都必须思考。
- **同伴解释**：学生用彼此语言解释，往往比专家解释更贴近 novice 思维。
- **即时反馈**：教师看到 class-wide 误解分布，可 targeted 讲解。
- **Metacognitive**：答错后讨论修正，强化「我原来以为 X，其实 Y」的反思。

## 其他主动学习策略（适用于大学）

### Think-Pair-Share

1. 教师提问 → 2. 独立思考 1–2 分钟 → 3. 两人讨论 → 4. 几组分享。

适合：概念辨析、伦理讨论、开放性问题。大班可用。

### 一分钟论文（Minute Paper）

下课前：「今天最重要的一个概念是什么？还有什么不清楚？」

2 分钟写作，收上来或在线提交。教师据此调整下节课。

### 案例教学法

商学院、法学院、医学院常用。给真实或仿真案例，小组分析、决策、辩护。

关键：案例需**足够复杂**以引发讨论，但有明确的学习目标 anchoring。

### 翻转课堂（Flipped Classroom）

课前：看视频/阅读完成 lower-order 学习。课内：讨论、练习、项目——做 higher-order 工作。

注意：翻转不等于「课前看视频 + 课上继续讲」。课内时间必须 reallocated 到主动学习。

### 同伴互评（Peer Review）

学生互相评价草稿（论文、设计、代码），依据 rubrics。

需培训：如何给 constructive feedback；教师 spot-check 互评质量。

## 大班课主动学习的特殊考量

| 挑战 | 对策 |
| --- | --- |
| 物理空间（固定座位） | 相邻 2–4 人讨论；不要求全班移动 |
| 时间压力 | 每 15–20 分钟一个 3 分钟活动，而非整节活动课 |
| 参与不均 | 随机抽组报告；written response 先于 oral |
| 内容覆盖焦虑 | 减少覆盖量，加深理解；meta-analysis 表明成绩反而提高 |

## 主动学习的局限与注意事项

1. **先备知识不足时**：开放探究可能变成无效搜索——需先确保 minimum foundation（见认知负荷理论）。
2. **实施质量差异大**：同名「讨论课」效果可天差地别——需要 structured tasks 和 clear accountability。
3. **学生 resistance**：部分学生偏好「清晰讲授 + 明确考点」——需 explain why，并用 early wins 建立 trust。
4. **教师 preparation**：好的 ConcepTest 和案例需投入时间——可从 shared question bank 起步。
