# 大班课教学策略（100+ 人）

> 面向 100+ 人大学讲授场景的互动与评价策略，整合 Freeman (2014)、Mazur PI 及 Chickering 原则。

**文献性质**：实践指南综述（二次整理，含本仓库 pku_salon 沙龙经验）

## 大班的核心挑战

| 挑战 | 表现 |
| --- | --- |
| 互动覆盖 | 点名提问只触及少数人 |
| 反馈延迟 | 作业批改周期长，形成性 loop 弱 |
| 认知负荷 | 信息密度高，学生容易「听懂但不懂」 |
| 动机分化 | 前排 engaged、后排 disengaged |
| 物理约束 | 固定座位、麦克风、投影限制 |

**误区**：「大班只能讲、不能互动。」Freeman et al. (2014) 表明 Peer Instruction、clicker、think-pair-share 在大班同样有效，只是需 structured design。

---

## 互动设计：低门槛、高覆盖

### 全员响应（Whole-class response）

- 「认为 A 的举手 / 认为 B 的举手」——1 秒内看全班分布。
- Clicker 或在线 poll（雨课堂、学习通、Mentimeter）。
- 不要求个别学生长篇发言。

### Think-Pair-Share（2–3 分钟版）

1. 教师提问（ConcepTest 或 open question）。
2. 独立思考 30–60 秒。
3. 邻座 2 人讨论 1–2 分钟。
4. 随机抽 2–3 组 share（或只看 poll 结果）。

### Peer Instruction 流程

见「主动学习与同伴教学」语料——特别适合 100+ 人 STEM 大班。

### 一分钟写作 / muddiest point

下课前 1 分钟：「今天最 unclear 的一点？」在线收集，下节课开头 address top 3。

## 讲授节奏与认知负荷

大班常 tendency 讲太快——内容多、怕讲不完。

**建议**：

- 每 15–20 分钟一个「停顿点」：提问、小结或 1 题练习。
- 新概念密度：每 10 分钟 ≤ 2–3 个需独立理解的新概念。
- 整体—部分—整体：先给章节 roadmap，再展开，最后 recap。
- 录播/在线模块承担 lower-order 内容，课内做 higher-order——翻转的变体。

## 助教（TA）体系

大班 quality 高度依赖 TA：

| 角色 | 职责 |
| --- | --- |
| 习题课 TA | 小班讨论、作业讲评 |
| 批改 TA | 统一 rubrics、抽样 inter-rater reliability |
| 答疑 TA | office hour、论坛 moderation |
| 课堂 TA | 走动观察 pair discussion、收集 muddiest point |

**教师需做**：TA training（rubrics、学术诚信、常见误解）、weekly sync meeting。

## 形成性评价在大班

- **Weekly 低 stakes 在线小测**（5 题，自动批改 + 解释）。
- **Clicker 分**（参与分，非对错分）——激励 engagement。
- **Midterm 前 mock exam** + 集体讲评 common errors。
- **Sample exam questions** 提前发布——减少「猜题」焦虑。

避免：只有期末一次 high-stakes，中间无 evidence。

## 课堂管理细节

- **前排 empty seat 问题**：early semester 鼓励坐前；walk around during pair work。
- **手机/笔记本**：明确 policy（部分教师 allow note-taking device，ban 无关浏览）。
- **迟到/早退**：大班难管——靠 engaging content 和 in-class points 自然减少。
- **录音/录像**：按学校 policy 声明是否允许学生 recording。

## 与北大教学沙龙经验的连接

北大青年教师沙龙常见主题与大班策略高度相关：

- **同伴讨论**替代点名——两轮作答看正确率变化。
- **举手示意式**全员响应——「选 A 的举手」。
- **低门槛、高覆盖**——不要求个别学生长篇发言。
- **板书 vs 课件**——大班全屏 PPT 易 lose 学生；保留板书展示思维路径。
