# 学术诚信与 AI 检测局限

> 价值导向的诚信治理、披露悖论与检测工具不可靠性研究综述。

**文献性质**：学术诚信机构框架 + 检测工具实证研究  
**核心出处**：ICAI Fundamental Values；Weber-Wulff et al. (2023)；Perkins et al. (2024)  
**整理说明**：六项价值据 ICAI；检测局限据 Weber-Wulff 与 Perkins 等实证。  
**核实日期**：2026-08-06

## 学术诚信六项价值（ICAI）

International Center for Academic Integrity 第三版提出 [1]：

| 价值 | 在 AI 时代的含义 |
| --- | --- |
| **Honesty（诚实）** | 如实披露 AI 使用 |
| **Trust（信任）** | 师生互信；policy 清晰可执行 |
| **Fairness（公平）** | 不因工具 access 或检测误报不公 |
| **Respect（尊重）** | 尊重他人成果与知识产权 |
| **Responsibility（责任）** | 对提交内容承担最终责任 |
| **Courage（勇气）** | 在灰色地带主动询问而非投机 |

## 政策应区分四类行为

| 类型 | 示例 |
| --- | --- |
| **允许 + 披露** | 用 AI 做 grammar check 并声明 |
| **禁止** | 用 AI 代写核心论证 |
| **专业/安全禁区** | 上传未公开研究数据、患者信息 |
| **程序要求** | 答辩质询、提交 prompt log |

中国研究生论文指南同样强调：**开放 / 有限 / 不可使用** 分场景管理 [3]。

## 为什么不能依赖 AI 检测器

Weber-Wulff 等 (2023) 对多款 AI 文本检测工具的系统测试表明：**准确率不稳定，简单改写即可显著降低检测效果** [2]。

Perkins 等 (2024) 发现：规避性处理可使检测准确率下降约 17.4%，**不支持将检测器用于单独认定违规** [4]。

**高校共识**（剑桥、MIT、哈佛等）：检测软件**不可靠**，不宜作为正式调查的唯一证据 [5][6]。

## 「Competence penalty」与披露悖论

研究提示：学生**披露** AI 使用后，评价者可能给出更低分数——即使 work quality 相同 [7]。

**教学回应**：

- Rubric 明确评「学习证据」，非「是否用过 AI」。
- 区分「违规未披露」与「合规披露」。
- 口试/过程证据验证真实能力。

## 正当程序（Due process）

认定学术不端应结合 [1][7]：

1. 任务要求与 policy 是否清晰
2. 过程证据（draft、log、时间戳）
3. 学生解释机会
4. 教师专业判断
5. **不以检测分数单独定案**

## 与中国政策的衔接

- 教育部等《「人工智能+教育」行动计划》（2026）要求防范学术造假、建立风险响应 [8]。
- 北大 AI 科研诚信平台汇集多校规范，强调**全过程留痕与质询** [9]。
- 期刊层面（如《中国人民大学学报》2025 声明）要求投稿 AI 使用说明 [10]。

## 边界与风险

| 误区 | 风险 |
| --- | --- |
| 一刀切禁用 | 隐性使用 + 职业素养缺失 |
| 依赖检测 | 误伤非母语者、残障学生 |
| 只罚不教 | 缺少 AI literacy 与 redesign |
| 披露过度繁琐 | 形式化、无效日志 |
