# SARPS：六策略与 AI 评价整合框架

> Cecilia Ka Yuk Chan & Tom Colloton (2024) 的 assessment redesign 策略及课堂应用。

**文献性质**：开放获取专著章节提炼  
**核心出处**：Chan, C. K. Y., & Colloton, T. (2024). *Generative AI in Higher Education*  
**整理说明**：SARPS 与 AI Assessment Integration Framework 据 Routledge OA 版 Ch.4 归纳。  
**核实日期**：2026-08-06

## 来源标注说明

SARPS 全称 Six Assessment Redesign Pivotal Strategies，见 Chan & Colloton [1]。

## 框架定位

Chan & Colloton 强调：GenAI 应 **co-** 而非 replace 人类 touch [1]。评价 redesign 须同时满足 **authenticity、integrity、genuine learning**，并引入 **九种 GenAI 时代评价类型**（与 SARPS 联用）。

## SARPS 六策略（操作向）

| # | 策略 | 做什么 | 课堂/作业示例 |
| --- | --- | --- | --- |
| **S1** | **明确 learning evidence** | 先定「要证明什么能力」 | 写出「本作业证明：能 X，不能仅靠 AI」 |
| **S2** | **分层 AI 允许度** | 按任务设 AIAS/政策 |  outline 允许 AI 1；final code 禁止 AI |
| **S3** | **过程性 artifact** | 收集 draft、log、reflection | PROCESS 模板（见 `Human-Effort与PROCESS作业模板.md`） |
| **S4** | **对话/表现性证据** | 口试、演示、live coding | 随机 3 分钟 code walkthrough |
| **S5** | **情境化与个性化** | 本地数据、个人经历、实时素材 | 用本校公开数据集；Interview 本地 stakeholder |
| **S6** | **元评价 AI** | 评 AI 输出、改 prompt、说明增值 | 「找出 AI 法律分析中的 3 处漏洞」 |

## AI Assessment Integration Framework（简）

与 SARPS 配合的**设计顺序** [1]：

```text
Learning outcome → 选择评价类型 → 定 AI 整合级别 → 选 SARPS 组合 → 写 brief + rubric
```

**原则**：每种评价类型对应**不同 AI 整合方式** — 不能 whole course 一刀切 AIAS。

## 九种 GenAI 时代评价类型（应用索引）

| 类型 | AI 整合思路 | SARPS 重点 |
| --- | --- | --- |
| 传统笔试（closed） | AI 禁止 | S4 |
| Take-home essay | 高风险 — redesign 或 AIAS 0 | S1,S3,S5 |
| Project / portfolio | 过程 + 展示 | S3,S5,S6 |
| Oral / viva | 验证 authorial | S4 |
| Peer assessment | AI 辅助 peer 训练 | S2,S6 |
| Authentic case | 真实情境 | S5 |
| AI-augmented task | 必须用 AI 批判/改进 | S6 |
| Staged assessment | 多阶段门槛 | S3 |
| Reflective journal | 元认知 | S3,S6 |

（类型名称据 Chan & Colloton 第 4 章思想归纳，实施时以原文为准 [1]。）

## 15 分钟「SARPS 体检」工作表

对**一个** summative assignment 回答：

1. 若学生用 AI 完成全部，我还剩什么 evidence？→ 若答案「很少」，触发 S3–S6  
2. AIAS 是否写在 brief 里？→ S2  
3. 有无 oral/performance 成分？→ 若无且 stakes 高，加 S4  
4. 任务是否 generic prompt 可解？→ S5 情境化  
5. 学生是否曾练习 critique AI？→ 若无，加 formative S6  

## 边界与风险

- 九类型 + 六策略并用可能**过载** — 每学期先改 1–2 个 high-stakes 作业。  
- 开放获取书含技术章节（神经网络史）— 教学应用以 Ch.3–5 为主 [1]。  
- 与内地校规对齐时引用清华/北大指南 [2]。
