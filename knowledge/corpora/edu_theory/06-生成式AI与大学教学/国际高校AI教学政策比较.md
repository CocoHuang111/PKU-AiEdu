# 国际高校 AI 教学政策比较

> Stanford、MIT、Harvard、Cambridge 等校的 AI 教学治理要点对照（截至 2026-08）。

**文献性质**：高校教学中心官方指南归纳（二次整理）  
**核心出处**：Stanford AIMES；MIT TLL；Harvard FAS OUE；Cambridge Blended Learning Service  
**整理说明**：各校政策为**课程级自主**为主；本文归纳共性，不暗示统一标准。  
**核实日期**：2026-08-06

---

## 来源标注说明

斯坦福 AIMES 见 [1][2]；MIT 见 [3][4]；Harvard FAS 见 [5]；Cambridge 见 [6]。

## 共性结构

| 维度 | 国际名校共识 |
| --- | --- |
| **政策层级** | 校级提供原则与资源；**任课教师**定课程 policy |
| **syllabus** | 必须在开学初明确 AI 规则并讨论 |
| **三档取向** | 严格限制 / 混合 / 鼓励探索（Harvard FAS 提供示范语言 [5]） |
| **integrity** | 未披露的使用在 summative 作业中通常视为 misconduct |
| **检测器** | **不可靠**，不宜作为调查唯一依据 [4][6] |
| **redesign** | 强调 assignment & assessment 重构 [3][1] |
| **equity** | 工具 access、隐私、语言学习者 [3][5] |

## 斯坦福大学（AIMES）

**文件类型**：教学 initiative + Teaching Commons 指南 [1][2]

| 要点 | 内容 |
| --- | --- |
| **默认规则** | 无明确 statement 时，AI = outside assistance，substantial use 完成 assignment **禁止** |
| **三路径** | AI-critical / AI-limited / AI-inclusive（见 `斯坦福AIMES框架与策略.md`） |
| **AISAC 原则** | Human oversight、alignment、transparency 等 |
| **资源** | AIMES Library of Examples 收录真实课程 artifact [2] |

## MIT（Teaching + Learning Lab）

**文件类型**：GenAI & Your Course 资源页 + Quickstart PDF [3][4]

| 要点 | 内容 |
| --- | --- |
| **设计循环** | 重审学习目标 → 明确期望 → 重构作业 → 考虑公平与隐私 |
| **syllabus** | 必须含 AI acceptable-use statement；首堂讨论 |
| **引用** | 若允许 AI，须规定 cite/document 方式 |
| **检测** | Quickstart 提醒考虑检测软件局限 [4] |
| **AIAS** | 引用 Updated AI Assessment Scale 作为沟通工具 [4] |

## 哈佛大学（Faculty of Arts and Sciences）

**文件类型**：OUE Generative AI Guidance（2023 起）[5]

| 要点 | 内容 |
| --- | --- |
| **校级** | **不强制**全校统一 policy；提供三类示范语言 |
| **Canvas** | 要求将 policy 发布在课程站点 |
| **数据** | 援引全校 AI 指南：勿将 non-public 数据输入第三方 AI |
| **学生责任** | 不同课程 policy 不同——学生须逐课确认 |
| **资源** | Bok Center、HUIT AI 指南链接 [5] |

## 剑桥大学

**文件类型**：Generative AI and Assessment 声明（院系落地）[6]

| 要点 | 内容 |
| --- | --- |
| **校级** | 无单一全校 summative 规则；支持院系/discipline 制定 |
| **misconduct** | 未适当 acknowledge 的 GenAI 内容在 summative 中属违规 |
| **检测** | **明确不推荐**依赖 AI detection software |
| **staff** | 不得向 GenAI 上传、复制或分享学生作业 [6] |
| **设计** | 推荐 personal reflection 等 AI 难复制元素 |

## 与中国高校对照

| 议题 | 国际常见做法 | 中国近期做法（见 `中国高校生成式AI政策综述.md`） |
| --- | --- | --- |
| 校级文件 | 原则 + 资源（清华类似） | 行动计划 + 教师指引 + 研究生论文指南 |
| 默认立场 | 斯坦福：无声明即禁止 | 强调 disclosure + 分场景 |
| 数据 | FAS/HUIT、清华数据安全原则 | 敏感/涉密/未授权数据禁止 |
| 学位论文 | 各校研究生 handbooks | 全国学会统一指南 + 答辩质询 |

## 对课程设计的启示

1. **借用示范语言时须本地化**——勿照搬外校 honor code。
2. **优先引用本校**文件；国际作对照。
3. **AIMES Library** [2]、MIT Quickstart [4] 可作 assignment 范例来源，但须重写 rubric 与 policy。
4. 与 `09-AI时代的评价与诚信/`、`高校AI课程政策设计要点.md` 配套使用。

## 边界与风险

- 各校 2023–2025 政策仍在迭代——以官网为准。
- Crimson 等媒体报道 [7] 可作背景，**引用以 OUE/CTL 官方页为准**。
- 比较不是为了排名，而是为了**可执行的 policy 要素清单**。
