# Electromagnetism & TEAL Simulations

8.02 Physics (Course 8)     ![electromagnetism](https://openlearning.mit.edu/sites/default/files/styles/event_news_detail/public/residential-innovations/electromagnetism.jpg?itok=eaTOgdNk)       Faculty/Instructor  John Belcher    Digital Innovations & Tools  Simulations & Visualizations

TEAL Simulation Framework is an environment for creating, presenting, and controlling simulations that represent physical and mathematical concepts. A single simulation may run as either a Java application or Applet. More details: [web.mit.edu/viz/soft/visualizations/visphysics/visphysics](http://web.mit.edu/viz/soft/visualizations/visphysics/visphysics.htm) and [web.mit.edu/viz/EM/index](http://web.mit.edu/viz/EM/index.html).
