# Interactive Plots Help Students to Understand How Parameters Change a Function

10.50 Chemical Engineering (Course 10)           Faculty/Instructor  Joey Gu    Digital Innovations & Tools  Active Learning Simulations & Visualizations

The students’ reception of a learning experience can inform teaching decisions. Professor Joey Gu wanted to create documentation for engineering and mathematics lessons that would make the learning experience more approachable. He used Desmos to incorporate plots that could be manipulated in real-time. Using the interactive plots, students had a visual of how parameters could change a function’s behavior and how a solution could change over time. Difficult concepts became understandable because lectures took into consideration the needs of the students.
