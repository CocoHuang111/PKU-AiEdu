该案例匹配课程主题为经济与管理分析，面向15.010（Management）核心课程学生，解决学生背景差异大、需从解题转向问题解决式思维的教学问题。实施策略为两次学期中采用翻转课堂：课前观看语音动画视频并完成概念检测题；课中开展小组‘Lab’任务，应用视频所学解决新问题；教师巡场指导并组织全班讨论。工具含MITx平台、动画视频、概念检测题与小组协作结构。评价方式为学生自评调查（n=129），测量对课堂应用视频内容的认可度。已陈述效果包括95%学生认同‘课堂允许复习与应用视频所学’，86%希望增加翻转环节，课程评价定量与质性指标均较上年提升，学生书面反馈高度肯定翻转模式对准备度、讨论与团队协作的促进作用。
