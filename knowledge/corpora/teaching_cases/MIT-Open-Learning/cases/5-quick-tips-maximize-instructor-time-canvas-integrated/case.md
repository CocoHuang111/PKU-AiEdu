# 5 Quick Tips to Maximize Instructor Time with Canvas-Integrated Tools

Office of Digital Learning

Updated 7/28/25

Thinking about how to quickly take up instructional practices utilized by other MIT faculty and instructors? These 5 tips pull ideas from the MIT Ad Hoc Committee Report on [Leveraging Best Practices from Remote Teaching for On-Campus Education](https://openlearning.mit.edu/sites/default/files/inline-files/LeveragingBestPracticesReportAug9.pdf).

**1. Use**[**Slack**](https://canvas.mit.edu/courses/3156/pages/slack?module_item_id=512474)**to increase student engagement with each other and/or with instructors/TAs.**

Students can post and answer each other’s questions, ask the instructors/TAs questions, and search posts/replies for information. Instructors/TAs can address FAQs for everyone to see, and gather input from students to guide class discussions. Set up is easy:

- Enable the [Slack integration on Canvas](http://kb.mit.edu/confluence/display/istcontrib/Get+Started+with+Canvas+Slack+Integration+%28Beta%29) to auto-sync the class roster.
- Create [Slack channels](http://kb.mit.edu/confluence/display/istcontrib/MIT+Slack+Enterprise+Grid+Landing+Page) (e.g., by topics, projects/groups, or weekly assignments).
- View [examples of MIT instructors](https://openlearning.mit.edu/mit-faculty/residential-digital-innovations?f%5B0%5D=digital_innovations_tools%3A152) using Slack, and watch a Slack [xTalk](https://www.youtube.com/watch?v=TgKNmWhvDw0).

**2. Use**[**Gradescope**](https://canvas.mit.edu/courses/3156/pages/gradescope)**to reduce grading time and improve feedback given to students on psets, quizzes, or exams**.

Instructors/TAs can build assignments in advance, and set-up/reuse rubrics and annotations for precise, actionable feedback. Multiple graders can maintain consistent feedback, and quiz data helps identify students’ common mistakes. To set up:

- Add [Gradescope](https://canvas.mit.edu/courses/3156/pages/gradescope) to the Canvas course navigation menu.
- Watch the demo videos [here](https://youtu.be/5OLkwBwS9eY?t=730) and [here](https://youtu.be/C8EfX-nArr0?t=2511).
- View [example of an MIT instructor](https://openlearning.mit.edu/mit-faculty/residential-digital-innovations/frequent-low-stakes-testing-more-learning-less-stress) using assessment to support student learning.

**3. Get to know student names with**[**Photo Grid**](https://kb.mit.edu/confluence/display/istcontrib/Photo+Grid+LTI+tool+in+Canvas)**.**

In addition to viewing student photos, instructors can learn students' pronouns and name pronunciations (if a student has added these in WebSIS). Here's how:

- [Enable the Photo Grid](https://kb.mit.edu/confluence/display/istcontrib/Photo+Grid+LTI+tool+in+Canvas) LTI tool in Canvas.
- View, sort and filter by section or group.

**4. Pre-schedule class meetings using**[**Zoom**](https://canvas.mit.edu/courses/3156/pages/zoom)**in Canvas, so that recorded sessions later automatically appear on the Canvas site.**

By setting up Zoom meetings in Canvas, the entire class is invited and the meeting is added to the Canvas class calendar. Zoom also integrates with Panopto to automatically push the recorded meetings to the Canvas course site. One-time set-up:

- Schedule [single or recurring Zoom meetings on Canvas](http://kb.mit.edu/confluence/display/istcontrib/Scheduling+a+Zoom+Meeting+from+within+Canvas).
- Integrate [Zoom with Panopto](https://canvas.mit.edu/courses/3156/pages/panopto-integration-with-zoom-+-canvas).

**5. Plan ahead for lecture capture to have the option for students to view and re-view lectures or presentations.**

When students need to catch up on a missed class or prefer to watch lectures at their own pace, they find it helpful to have recordings. Instructors/TAs can modify access to the recordings, though lecture capture requires at least a day’s notice. Start now:

- Reserve [classrooms with automated lecture capture](https://canvas.mit.edu/courses/3156/pages/classroom-lecture-capture).
- Schedule [MIT Video Productions to record](https://mvp.mit.edu/schedule-services/) in a classroom.
- Learn about other [self-service options](https://canvas.mit.edu/courses/3156/pages/options-for-self-service-lecture-recording) (e.g., iPad or other tech).
