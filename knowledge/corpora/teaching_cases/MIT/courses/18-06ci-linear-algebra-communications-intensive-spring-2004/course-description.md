## Course Description

This is a communication intensive supplement to Linear Algebra ([18.06](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/)). The main emphasis is on the methods of creating rigorous and elegant proofs and presenting them clearly in writing. The course starts with the standard linear algebra syllabus and eventually develops the techniques to approach a more advanced topic: abstract root systems in a Euclidean space.
