## Course Description

This resource aims to enhance students’ learning of kanji by providing a series of video lectures that cover the kanji characters in [Tobira](https://tobiraweb.9640.jp/) lessons 6–10. The video lectures not only teach how to write kanji but also provide stories behind the kanji characters.
