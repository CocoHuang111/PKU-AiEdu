18.065 数据分析、信号处理与机器学习中的矩阵方法，数学系本科，先修 18.06 线性代数，主题含电气工程、信号处理、应用数学、计算和线性代数。课程复习线性代数并用于概率统计与优化，讲解机器学习、深度学习和神经网络。内容覆盖列空间、矩阵分解、正交列 Q、特征值与特征向量、正定与半正定矩阵、奇异值分解（SVD）、Eckart-Young 最近秩 k 矩阵、范数、最小二乘、Ax=b、约束最小化、随机矩阵乘法、低秩变化和 A(t) 导数。每周 3 次、每次 1 小时讲座；成绩由作业、实验和最终项目决定。项目可 2-3 人小组，推进数值例子、应用、算法测试或计算，春假前后交 proposal，最后节课截止，有视频、播客和习题集。
