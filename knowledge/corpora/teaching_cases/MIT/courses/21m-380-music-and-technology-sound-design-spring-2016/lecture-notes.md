## Lecture Notes

This page presents the complete lecture slides as presented in class, plus selected lecture outlines that complement the lecture slides.

### Lecture Slides

The complete set of lecture slides are given here compiled in a single file. Within the file, the start of each lecture is bookmarked for ease of direct access. Your PDF viewer should open with the bookmarks index visible, alongside the slides window.

**Important**: The slides include links to a set of audio examples and Pd patches, also provided below. For these linked examples to work correctly, you must download and save the lecture slides PDF, audio examples, and Pd patches together in the same directory on your computer, as summarized in the [Lecture Slide Instructions (PDF)](https://ocw.mit.edu/courses/21m-380-music-and-technology-sound-design-spring-2016/resources/mit21m_380s16_lecinstruct/). Also be sure to install Pure Data to run the Pd patches, as directed on the [Tools](https://ocw.mit.edu/courses/21m-380-music-and-technology-sound-design-spring-2016/pages/tools/) page.

[Lecture slides (PDF - 19.4MB)](https://ocw.mit.edu/courses/21m-380-music-and-technology-sound-design-spring-2016/resources/mit21m_380s16_lec_slides/)

[Audio examples (ZIP - 4.6MB)](https://ocw.mit.edu/courses/21m-380-music-and-technology-sound-design-spring-2016/resources/21m380_examples/)

[Pd patches](https://mitp-content-server.mit.edu/books/content/sectbyfn/books_pres_0/8375/designing_sound.zip/index.html) from Andy Farnell’s *Designing Sound*

While viewing the slides on your screen, clicking on any “play button” icon
