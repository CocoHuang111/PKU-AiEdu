# 古生物形态学定量分析实践平台建设

**项目**：2018年本科教学改革项目  
**单位/负责人**：地球与空间科学学院 熊文涛  
**汇编页码**：第161–169页

## 一、教改项目设计思路

### 1. 项目背景与目标

报告写，国内外古生物学家在教学和科研中，一般用自己编写、未在公开出版物发表的代码，对形态测量数据做运算。形态数据计算涉及大量多维计算与分析，人工难以完成，这妨碍了形态测量方法在定量古生物教学中的普遍使用。国内古生物学本科教学主要使用 PAST（PAleontological STatistics）或 SPSS 等软件做形态学定量研究。这类软件不是开源软件，教学实习又需要对原始数据做自定义处理与分析，软件内置的程序包和模块较难满足需求。

项目依托地质学专业本科生古生物学课程及《综合地质实习（三峡地区）》，建设古生物形态学的实践平台。做法是按实践课程内容，用 R 语言建设教学所需的形态定量计算与分析模型库，提供形态测量数据的自主处理，引导学生做定量分析方面的专业训练和实践。

### 2. 实施方案

平台在常用古生物形态学定量分析数据库之上，结合教学实践过程，把数据分析、处理和展示放在一起，做成师生可用的线上系统，供学生自主学习和实践。实施工作分为五项：

1. 基础平台软件搭建；
2. 古生物形态学概念及基础数据库建设；
3. R 语言与统计学基础教程建设；
4. 用 R 语言处理古生物形态学数据的案例建设；
5. 古生物形态学数据处理与分析的自主模块建设。

## 二、教改项目实施过程

项目建设了“北京大学古生物形态学定量分析实践平台”。平台以古生物形态学数据处理方法为核心，包含教程库、分析模板库和案例实践库，并整合 R-IDE Server 云平台。功能覆盖基础概念、定量数据分析演示和在线数据处理。除项目组成员外，地质学、古生物学、统计学、计算机专业的数十名本科生和研究生参加了建设。实施内容为基础平台、实习基础内容、数据处理模块和在线实践模块。

### 1. 基础平台搭建

平台基于 H5、JavaScript、PHP 和 MySQL。前端按 W3C 标准用 HTML5 开发，数据分析教程和代码用 R-Markdown 展示，以便与代码、数据表格动态交互。平台兼容 PC 和移动端，学生可在不同客户端调用教程、数据处理模板和后台 IDE。

后端除资源管理外，在 RStudio-Server 上开发了在线 R-IDE。分析数据、编辑代码和演示结果都放在其中。学生从 PC 或移动端登录后直接调用 RStudio-Server 做分析和处理，实时返回结果，不必再安装数据分析软件。结果保存在服务器上的个人目录。

### 2. 实习基础内容建设

报告把定量古生物学写成古生物学原理、数学方法与计算机技术的结合：用计算机应用数学理论和方法，分析古生物学及相关学科数据，研究化石的形态、分类、生活方式、分布和演化。这一部分收录定量分析中常用的概念、定义和研究方法，作为形态学定量分析的理论基础。教程包括：

1. 定量古生物的定义与研究历史；
2. 通用分析方法：回归分析、方差分析、主成分分析、聚类分析等；
3. 古生物定量分析方法：几何形态测量、地层分布分析、频谱分析等。

### 3. 数据处理模块建设

报告把数据处理与分析视为平台核心，并选择 R 语言以便把内容拆开、便于学习。知识点按《古生物形态学》等教材和古生物形态学数据集，循序呈现。项目完成了统计学基础、R 语言编程基础、算法分析及机器学习等模块。每部分包含教程、算法分析、代码设计和案例展示。学生了解基本方法后可以实践，用平台提供的数据和算法在线调试，并保存、下载输出结果。

主要内容有六块：

1. **统计学基础。** 用编程语言描述统计分析所需的基本知识，结合自带的 iris 植物叶片数据集做案例。内容包括统计学基础、方差分析、回归分析、参数估计、假设检验、数据描述性分析、应用多元分析、生存分析、时间序列。
2. **R 语言基础。** 数据结构从向量、列表、矩阵、数组、数据框、因子介绍，并做数据对象类型转换。编程部分从较简单的写法开始，包括数据对象命名、代码简化、自定义函数和代码调试。
3. **数据处理。** 在数据结构和编程之后，用古生物学数据做简单处理，包括数据说明、字符串处理、读取与导出、预处理、合并排序和抽样。
4. **数据可视化。** 把古生物学数据做成关联图像，便于地层分布分析、系统发育分析、群落划分和频谱分析。内容包括绘图基础、图形包、散点图、箱线图、小提琴图、马赛克图、等高线图、相关系数 QQ 图。附件中的两幅图分别是植物鸢尾花数据集的相关系数矩阵图，以及残差项的 Q-Q 矩阵图。
5. **机器学习。** 主要供学有余力、对机器学习感兴趣的学生参考。报告把机器学习写成用算法解析数据、从中学习并做出决定或预测，并指出典型的无监督学习（聚类分析与降维分析）在古生物形态学定量分析中有重要应用。内容包括神经网络、随机森林、降维与度量学习、KNN 最邻近算法、聚类分析、监督学习与无监督学习、特征工程、模型评估与选择。
6. **数据接口。** 提供 R 与其他语言或软件的接口，便于把平台中的结果转到其他语言平台，或调用其他平台和软件的数据。包括 C 语言、Python、Java 接口和 Oracle 数据库连接。

### 4. 在线实践模块建设

在线实践模块基于 RStudio-Server，实现在线编程、数据处理、实时返回结果和服务端存储，供学生运行代码、调试程序和做可视化分析。第三部分的案例都内置在该模块中，关键步骤有解释说明，用来引导学生自己做实习。

## 三、教改项目实施成果

报告写，平台与《古生物数据分析》《综合地质实习（三峡）》等课程结合，借助教程案例和 R-IDE 云平台，吸引学生用 R 语言和平台做古生物定量分析，作为古生物学类课程的补充。项目自述：取得了良好的教学效果。

与教改直接相关的完成项为：

- 建成《北京大学古生物形态学定量分析实践平台》；
- 定量分析教程实例 75 个；
- 定量分析 Rmd 文档 75 个；
- 数据分析代码案例 147 个；
- 完成基于 RStudio-Server 的古生物数据在线分析平台。

学生反馈均为项目自述。报告写，学生接触平台后兴趣较浓，主动学习古生物形态学定量分析和 R 语言数据处理；普遍反映 R 语言在古生物数据处理中灵活、方便、高效，平台为自主学习和实践提供了条件。经过一段时间，学生从数据处理入门到能独立使用 RStudio 做古生物数据分析。部分学生多次与项目组讨论 R 语言的具体应用，并参加模板库的补充。2 名同学用平台或 R 语言做了数据处理和可视化，并在此基础上撰写科研论文，等待投稿。论文尚未发表，不能从这篇结题报告确认投稿结果。

项目自述的辐射范围：北京大学、南京大学、电子科技大学、西北大学、北京科技大学、首都经贸大学、北方学院等高校的本科生和研究生参与了建设、测试和试用，并对平台做了推广；师生用户给予正面评价。

## 四、存在问题

原文第四节分“存在问题”“建设设想”“后续工作”三小节。问题本身只有一条；后两小节是后续打算，不是已经发生的故障。

收集到的古生物形态学定量分析数据较少。部分案例，如神经网络、监督学习，未能用古生物学数据集展示，与古生物学联系不够密切。计划在后续完善中，与《古生物学数据分析》及其他古生物学类课程结合，多收集数据集，完善案例库。

建设设想写在国内外生物统计、计算生物学已有 R 语言数据科学课程的背景之下，建议学校在生物、古生物学专业课程中引入一定的 R 语言数据科学内容。两条具体做法是：鼓励古生物学类任课教师在课程计划中安排一定学时的数据统计，引入 R 语言案例；把本平台作为相关课程的实习内容，学生课下使用平台完成教师布置的数据处理。

后续工作列为五项：基于 R 语言扩展古生物学定量分析实践；完善上述平台；更新数据处理模板库，与定量古生物学教学结合得更紧；持续指导学生用 R 语言和平台处理古生物学数据；把教程统一格式，整理为定量古生物学数据分析实践教材。

## 五、项目亮点与可迁移场景

### 项目亮点

- 平台要解决的是两件具体的事：形态测量依赖未发表的个人代码，以及 PAST、SPSS 等非开源软件难以按实习需要自定义处理。
- 一个系统同时放教程库、分析模板库、案例库和免安装的 RStudio-Server，PC 与移动端都能登录，计算结果留在服务器个人目录。
- 内容按学习顺序铺开：定量古生物概念和通用统计，几何形态测量、地层分布、频谱分析等学科方法，然后是 R 的数据结构与编程、古生物数据清洗、可视化；机器学习单列给学有余力的学生。
- 统计学入门案例用的是 iris 植物叶片数据；古生物数据用在后续的读取、预处理、合并和可视化。报告自己指出，神经网络、监督学习等案例当时还缺少古生物数据集。
- 与《古生物数据分析》和三峡《综合地质实习》结合，并完成 75 个教程实例、75 个 Rmd 文档和 147 个代码案例。

### 可沉淀为教学设计或 skill 的做法

- 定量实习平台的顺序：先概念和通用统计，再学科专用方法，然后语言与数据操作、可视化，最后把机器学习标成选学。
- 案例直接放进在线环境，关键步骤写上解释；学生在浏览器里改代码、看结果、下载输出，不把软件安装当成课前障碍。
- 示例数据要标明学科属性。若某类算法暂时只能用通用数据集演示，就在案例库中记一笔，并回到《古生物学数据分析》等课收集本学科数据后再替换。
- 平台作业的用法：任课教师布置数据处理，学生课下在平台完成，而不是只在课堂上观看演示。

### 可应用场景

- 地质学专业本科的古生物学形态测量实习，以及三峡一类综合地质实习中需要自定义处理化石形态、地层或谱系数据的环节。
- 已经有学科数据集、又不便把商业统计软件内置模块当作全部工具的古生物学小班或实习组；建设过程中还可吸收统计学、计算机专业学生参与模板和测试。
- 同一门课里的分层任务：全体学生完成统计、R 基础和古生物数据图件；神经网络、随机森林等模块留给主动联系项目组、并参与补充模板库的学生。
