# 超算创新竞赛

**项目**：2017年本科教学改革项目  
**单位/负责人**：信息科学技术学院 梁云  
**汇编页码**：第170–178页

## 一、教改项目设计思路

报告从计算技术的跨学科应用写起，把高性能计算列为由此产生的前沿方向之一，并认为它提高了研究效率，也带来新的教学和人才需求。文中列举2019年上半年的榜单情况：中国有220个超算集群进入世界超级计算机500强，总数居世界第一；太湖之光与天河-2A分别占据 TOP500 第三名和第四名。这些排名是报告引用的领域背景，不是本项目的比赛成绩。

项目要向校内同学普及高性能计算、宣传研究现状，并吸引学生做相关学习和研究。预期目标有三条：

1. 向全校同学宣传高性能计算，鼓励在学习科研中使用超算，并提高高性能计算在社会上的普及程度。
2. 与信息科学技术学院的体系结构、操作系统、并行计算等相关课程结合，在课外提升相关能力、积累实践经验。
3. 依托微信公众号宣传 SC、ASC 等国际比赛，招募本科生参赛；派出代表队参加比赛，开拓眼界，扩大北京大学在超算领域的声誉。

实践方案对应三项活动：成立兴趣小组，在多个院系招募同学，定期讨论，并以来自不同院系的学科背景分享前沿论文和技术；与 NVIDIA、IBM 等高性能计算企业保持合作，共同组织讲座，每周做有主题的队内培训和讨论并记录；组织参加 SC、ASC、CAPI 等比赛，并支持同学参加相关会议。

## 二、教改项目实施过程

项目以北京大学高能效计算中心和信息科学技术学院的多门计算机系统课程为依托，征集对高性能计算、并行计算、操作系统等方向感兴趣的同学，招募本科生30余人，成立兴趣小组，定期讨论技术和论文。为扩展超算应用场景，除信息科学技术学院计算机专业外，还招募了元培学院和工学院的同学。2017年立项后的工作分学生团体、硬件环境、企业合作、参会参赛和科研实践几方面。

### 1. 讨论条件与硬件

讨论会议室位于燕园大厦，配有白板和会议平板。讨论内容从系统管理到性能优化，从分子模拟到深度学习优化。整个项目周期组织了几十次讨论与交流。

为在真实硬件上练习，项目采购三台高性能服务器和一台高性能工作站。三台服务器组成小型超算集群，单精度计算能力超过 100 TFLOPS；工作站用于日常开发和实验。四台机器的配置为：

- 2×Xeon E5-2630，128 GB 内存，4×NVIDIA Tesla P100
- 2×Xeon E5-2690，384 GB 内存，4×NVIDIA Tesla V100
- 2×Xeon Silver 4110，128 GB 内存，4×NVIDIA Tesla V100
- Core i9-9900X，64 GB 内存，NVIDIA RTX 2080Ti

报告写，集群包含采购时 Intel 最新的 CPU 平台和 NVIDIA 最新的 GPU 平台，并采用 Mellanox 的 InfiniBand 互联卡，机器间互联带宽达 100 Gb/s。项目还配置了 FPGA 卡和嵌入式开发板。

### 2. 企业交流

项目与 NVIDIA 共同组织 OpenACC 研讨讲座，讨论快速代码优化；组织同学访问 IBM，就其 POWER 系统交流。与参赛赞助商北京容天汇海科技有限公司的合作方式是：供应商出资并出借参赛设备，超算团队提供宣传。

### 3. 会议

项目组织同学参加 GTC-2017。报告介绍，GTC 是 NVIDIA 的年度开发者大会，有企业展览和主流技术讲解。参会学生在会场接触硬件平台，并与参展企业交流。

### 4. 暑期培训

为使知识结构符合竞赛和其他学术活动的需要，暑期组织系统培训，形式以翻转课堂为主：每位同学负责一项主题的讲授，并布置与主题相关的实践项目。主题涵盖并行基本框架、加速硬件的编程、网络通信、复杂程序的配置和调试。培训之外，还通过参会和讲座邀请专家，就前沿领域和超算方法、趋势对队员做培训。

### 5. 参赛

项目组织同学参加在美国丹佛举行的 SC’17（高性能计算、网络、存储与分析国际会议）上的全球大学生超算挑战赛总决赛。项目自述成绩：总分第四、性能评测第四名。报告介绍，该会议公布半年期全球超级计算机排名，这场学生比赛是学生超算领域三大国际竞赛之一，HPL 结果收录到 Top500 榜单的 SCC 子榜；本队结果也进入该子榜。

项目还组织参加 CAPI 异构计算设计大赛。比赛关注 FPGA 相关的异构计算。团队用 OpenCAPI 的主机—FPGA 接口框架，实现与 FPGA 加速卡之间的高带宽、低延迟访问，并开发高性能 Bcrypt 应用。项目自述：因这一表现获得优胜奖，并增加了与主办方 IBM 的交流。

### 6. 科研训练与论文

项目面向参加同学开展科研训练，并指导撰写、发表两篇高性能计算论文。一篇以生物学为背景，复现基因背景的连通图算法，研究原始论文的实现细节与结果并加以讨论。另一篇讨论多体势能，探究不同架构下 LAMMPS 的优化。两文分别发表于 Parallel Computing 2017年刊和2018年刊。项目自述：同学反映，实验过程培养了严谨的科研习惯，撰写和投稿使他们熟悉了发表论文的流程。

## 三、教改项目实施成果

成果概述把过程概括为：实践活动、校内技术宣讲、国内外比赛、企业合作和论文发表。具体三条与实施过程相呼应，其中效果判断属于项目自述。

1. 定期理论培训和技术交流，以及软硬件实践。报告写，超算实践所用知识是其他专业课的扩展和应用；从参加同学的成长看，竞赛有助于理解专业课、促进对计算机系统结构的整体理解、提升学习效果。
2. 参加 SC’17 全球大学生超算挑战全球总决赛和 CAPI 异构计算设计大赛。项目自述：参赛师生与国内外团队交流，专业水平给评委留下印象，提升了学校的学术声誉；学生参观展览、听会议报告。北大超算队还与新加坡南洋理工大学、德国慕尼黑工业大学等校参赛队员建立联系并持续至今，报告称之为一项传统，并写这提升了国际声誉。
3. 把实践中较好的部分写成论文，发表在 Parallel Computing。报告特别写到复现文章：复现促进对学术严谨性的要求，也是进入科研的第一步，并为学院培养能在本科期间做科研实践的学生。

师生反馈均为项目自述。同学方面：超算训练把操作系统、编译原理、体系结构等课堂内容做了更深入的实践，并从高性能计算一侧接触编译器、文件系统、网络等；实践把各门专业课串联起来；项目中的科研锻炼有助于此后各自方向的科研，经过训练的学生得到各自导师的高度评价。过程中，同学自主组织讨论，并主动与指导教师和其他相关方向的教师交流。教师方面：同学在专业知识、动手能力和科研习惯上有较大提升，学生的自主性和主动性也使专业技能教学更方便。

辐射范围同样为项目自述。近两年在本科生中招募成员30余人，核心成员15人，覆盖本科各年级。成员主要来自信科和元培学院，也有工学院、物理学院；过程中还就学科问题咨询了生物、化学等学科的同学。借助系统管理经验，很多参加项目的同学成为各自实验室的服务器和网络管理人员；两位同学成为计算中心的学生网管。部分同学因这段经历获得较好的出国申请结果，已有多位毕业生前往 MIT、斯坦福等高校做超算相关方向的科研。出国去向是结题报告中的自述，不能从本文单独推出申请结果由本项目造成。

## 四、存在问题

报告列出的不是已经失败的活动，而是当时认为尚未做好、准备继续做的事。

现有活动资料没有很好地收集和组织。准备由同学完善文档整理，建立文档共享平台，便于传承和入门学习。

各项活动当时主要面向教改参与人员。后续考虑扩大讲座受众、把培训公开，并在现有组织和设施上协助或组织高性能计算理论课或实验课，面向全校不同专业背景做普及，使感兴趣的同学能在日常学习和科研中使用超算平台。

还计划深化与其他高校同类项目的交流，并与校内相关社团合作。另一项是推动与学校计算中心超算业务合作，增加实践机会，并辅助计算中心做超算知识普及。报告注意到，工学、物理等非计算机专业对超算平台的需求也比较大，更全面的普及有助于相关学科的工作。

## 五、项目亮点与可迁移场景

### 项目亮点

- 兴趣小组挂在高能效计算中心和体系结构、操作系统、并行计算等课程旁边，成员约30人，核心约15人，除信科计算机专业外包括元培、工学院，并接触物理、生物、化学的问题。
- 讨论有固定房间和几十次记录在案的交流；同时有一套可上机的小集群：三台服务器加一台工作站，单精度超过 100 TFLOPS，互联为 100 Gb/s InfiniBand，另有 FPGA 和嵌入式开发板。
- 暑期培训采用翻转课堂，主题就是竞赛必备技能：并行框架、加速硬件编程、网络通信、复杂程序的配置和调试。企业侧则是 NVIDIA 的 OpenACC 讲座、IBM POWER 访问，以及赞助商出借参赛设备。
- 参赛和论文是两条已完成的出口。SC’17 总决赛的项目自述成绩是总分第四、性能评测第四，HPL 进入 Top500 的 SCC 子榜；CAPI 赛题落到 OpenCAPI 与 Bcrypt。两篇 Parallel Computing 论文分别是基因背景连通图算法的复现，以及不同架构上 LAMMPS 多体势能的优化。

### 可沉淀为教学设计或 skill 的做法

- 竞赛培训的分工：每人讲清一个必备主题，并交一个与该主题绑定的实践作业，讨论和培训要留下记录。
- 硬件按“能验证想法”配置。理论讨论和上机使用同一批最新的 CPU、GPU 或 FPGA，互联带宽单独写进平台说明。
- 科研训练从复现开始：先对齐原论文的实现细节和结果，再讨论；另一类题目则是同一软件在不同架构上的性能优化。投稿流程本身被当作训练的一部分。
- 队伍延续的判断写在问题部分：活动资料若不进入共享文档，下一届就缺少入门材料；面向全校的普及若仍只对项目成员开放，工学、物理等有计算需求的专业进不来。

### 可应用场景

- 已开设体系结构、操作系统、并行计算的计算机专业：课外兴趣队约二三十人，用小型 GPU 集群和暑期翻转课堂准备 SC、ASC 一类学生超算赛。
- 需要跨学科算例的超算小组：讨论题目可以是分子模拟、深度学习优化或生物网络算法，队员来自信科以外的元培、工学或物理，并向生物、化学同学核对学科问题。
- 学校计算中心或实验室服务器管理：参加过集群搭建和系统管理的本科生，承担实验室网管或计算中心学生网管；若要做全校普及，须把讲座和培训从队内打开，并与计算中心的超算业务对接。
