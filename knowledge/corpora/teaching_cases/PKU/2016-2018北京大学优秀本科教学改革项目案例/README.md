## 课程思政示范课程档案

在用户授权的北京大学统一身份认证会话中，已取得教学档案袋平台66门课程的完整正文API数据，并全部结构化到 `course_ideology/`。每份包含课程简介、课程思政认识、元素对应表、教学方法与实例、效果评价、附件索引与来源；未改写的总JSON和66份单课程JSON保存在 `source/课程思政示范课程/`。

这66份档案与上述32份教改案例或教师专访可能存在课程重叠，因此数量表示“结构化文档数”，不直接表示互不重复的课程数。

## 整理原则

汇编中的29份结题报告按原文栏目整理为五部分：教改项目设计思路、实施过程、实施成果、存在问题，以及据此提炼的「项目亮点与可迁移场景」。前四部分只压缩和重组原材料，不补写原文没有的学习效果；原报告没有单列问题、或把下一步打算写进问题栏时，整理稿照实说明。项目获奖、学生竞赛、课程评估、报名人数、到课情况或个别学生成果均标为“项目自述”，不直接解释为教学法的因果效果。第五部分只抽取原文已经写出的做法，说明可复用的教学流程和适用课型。引用时应同时查阅原 PDF 对应页。

**当前数量**：98份结构化文档，包括29份汇编案例、3份官方公开报道案例和66份课程思政档案。
