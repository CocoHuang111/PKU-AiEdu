6.331 Advanced Circuit Techniques（高级电路技术）是研究生课。课程先简述原理，再让学生完成多路复用器（multiplexer）、采样保持器、增益控制放大器、模拟乘法器、DAC/ADC、功率放大器等先进电路的纸面设计，并向全班展示一个设计；实验强调现代模拟 building blocks。每周两次 1.5 小时讲座和一次 recitation。作业包括 Problem Set 1-6 与 Design Problem 1-3；教师审阅设计、个别反馈并组织 design-review 讨论，按 1、2、3 级评定。适合训练模拟与混合（analog-digital）电路设计、设计评审的研究生教学。
