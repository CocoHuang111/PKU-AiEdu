MAS.962《Common Sense Reasoning for Interactive Applications》（常识推理与交互应用）是媒体艺术与科学系研究生课，每周2小时讲座。课程探讨常识知识研究现状，主题含语言文化差异、推荐/游戏/教育应用、用户目标推断，以及OMCS、ConceptNet、EventNet等工具和Cyc、ThoughtTreasure、语义网等。作业有阅读讨论准备、论文摘要与评论；最终项目用常识知识实现用户界面，可个人或最多三人，需一页提案、CHI风格短论文和15-20分钟演示。适合人机交互、认知科学、媒体研究等方向，关注常识推理、跨文化沟通与界面设计的研究生教学需求。
