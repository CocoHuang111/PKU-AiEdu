MAS.836《交互环境传感器技术》（Sensor Technologies for Interactive Environments）是2011年春季研究生课程，涉及电子工程、数字系统、电子学与信号处理，适合传感器技术、人机界面（HCI）与泛在计算应用教学。课程先复习传感器信号调理电子学，再讲压力、应变、位移、接近、热、电场与磁场、光学、声学、RF、惯性、生物电等传感器架构与模态，并讨论简单传感器处理算法及有线/无线网络标准。每周1次3小时，讲座结合实验；作业含 problem sets、labs 和最终项目，含报告与课堂展示。考核为问题集30%、最终项目30%、实验表现30%、出勤/参与/阅读10%。
