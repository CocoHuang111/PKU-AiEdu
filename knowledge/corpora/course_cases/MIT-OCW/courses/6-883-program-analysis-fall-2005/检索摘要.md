6.883 Program Analysis 是 2005 年秋季 EECS 研究生研讨课，属计算机科学、软件设计与工程，研究面向软件工程任务的程序分析：静态分析涵盖抽象解释、类型系统、模型检验、决策过程（SAT、BDD）与定理证明；动态分析涵盖测试、故障隔离、模型推断与可视化，并聚焦编程工具的设计与实现。先修 6.170 和 6.042J 或教师许可，6.035 或 6.821 有帮助但非必需。教学采用论文研读研讨，学生读经典与当前论文、参与课堂讨论、做小练习，并完成 2-4 人学期团队研究项目；作业含 Assignment 1。适合研究生课程设计、教学活动设计与考核设计中的程序分析、软件工程工具、论文研讨与团队项目检索。
