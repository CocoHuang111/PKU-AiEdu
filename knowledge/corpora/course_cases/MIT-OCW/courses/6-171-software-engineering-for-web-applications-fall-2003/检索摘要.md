6.171《Software Engineering for Web Applications》是 MIT 电气工程与计算机科学系本科高年级课，面向已有编程与软件工程经验、修过 6.001 和 6.170 的学生，需教师许可。课程聚焦互联网应用特有挑战：并发、不可预测负载、安全风险、广域分布式计算、在不可靠连接与无状态协议上提供可靠有状态用户体验、需求中途变化、多模态界面。每周两次课。作业基于在线教材《Internet Application Workbook》，含内容管理、搜索、分布式计算、元数据等 problem sets，并有团队项目与代码评审。考核含期中、期末，适合软件设计、数据库、Web 应用、分布式系统教学。
