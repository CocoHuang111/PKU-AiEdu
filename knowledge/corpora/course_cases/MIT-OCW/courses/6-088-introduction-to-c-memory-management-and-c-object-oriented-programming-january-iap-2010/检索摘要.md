6.088《Introduction to C Memory Management and C++ Object-Oriented Programming》是 MIT EECS 本科课程，2010 January IAP 开设，属计算机科学、编程语言与软件设计工程。内容从简单 C 程序到 C 内存管理，再到 C++ 类与 STL。适合已有 Python、Scheme、Java 等基础、想熟悉 C/C++ 且无 C/C++ 经验者。讲座 3 次/周、2 周、每次 1.5 小时；作业含二叉搜索树增删查、内存管理、C++、继承与多态，需用 GCC、GDB、Valgrind 编译测试和查内存泄漏。适合中文检索 C/C++ 入门、内存管理、面向对象编程、课程设计与作业设计。
