6.189《A Gentle Introduction to Programming Using Python》是 MIT IAP 2011 的本科 Python 入门课，面向学习动机强、几乎没有编程经验的学生，重点为程序规划与组织和 Python 语法。内容覆盖条件、循环、函数、字符串、列表、列表推导式、类、继承和复习；作业含 homework、Hangman 项目、项目和最终项目。课程 3 周密集安排讲座与必须参加的实验，使用 Python 2.6.x，考核无字母等级，用 +/Check/- 评价问题集尝试、测试和注释，通过需多数 +，并为 6.01 做准备。适合课程设计、教学活动设计、Python 教学、作业与考核设计等中文检索。
