8.251 String Theory for Undergraduates（本科弦论）是2007年春季Physics系本科课程，主题涉及理论物理与量子力学。面向已接触狭义相对论和基础量子力学的学生，先修8.033、8.044和8.05，每周两次讲座，每次1.5小时。课程基于Zwiebach的A First Course in String Theory，把弦论作为相对论弦的量子力学，内容涵盖Lorentz变换、光锥坐标、紧致维度、相对论电动力学、Nambu-Goto作用量等。考核含每周作业、Test 1、Test 2和Final exam，分别占35%、20%、20%、25%；作业不接受迟交，可删最低一次。
