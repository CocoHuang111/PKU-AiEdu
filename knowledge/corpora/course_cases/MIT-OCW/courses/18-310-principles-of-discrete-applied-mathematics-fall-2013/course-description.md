## Course Description

This course is an introduction to discrete applied mathematics. Topics include probability, counting, linear programming, number-theoretic algorithms, sorting, data compression, and error-correcting codes. This is a [Communication Intensive in the Major](https://registrar.mit.edu/registration-academics/academic-requirements/communication-requirement/ci-m-subjects) (CI-M) course, and thus includes a writing component.
