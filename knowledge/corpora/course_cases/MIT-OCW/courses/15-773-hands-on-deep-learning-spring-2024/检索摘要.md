15.773 Hands-On Deep Learning（动手深度学习）是斯隆管理学院春季2024研究生课，半学期，每周两次讲座、每次1.5小时。内容覆盖深度神经网络基础与训练、CNN 图像视频、transformers 与 NLP、生成式大语言模型如 ChatGPT、文本到图像如 Midjourney，强调用 Python 动手处理非结构化数据。适合需深度学习、计算机视觉、NLP、生成式AI课程设计的研究生；先修 Python 与训练/验证/测试、过拟合/欠拟合、正则化。教学活动含讲义、视频、问题集、编程作业与 Colab；考核含参与10%、两次作业各25%、团队期末项目，需提案、5-10页报告和展示。
