12.950《Parallel Programming for Multicore Machines Using OpenMP and MPI》是地球、大气与行星科学系研究生课程，2010年January IAP开设，主题为计算机科学与软件设计与工程。课程介绍共享与分布式内存编程基础，讲授用OpenMP和MPI编写代码，并面向数值应用提供并行计算动手实践，涉及OpenMP指令、数据作用域与性能问题，以及MPI点对点、集合通信等。课程为一周密集授课，五次课，每次两小时，需教师许可；含5次问题集作业，包括OpenMP/MPI示例。考核为课堂参与50%、作业50%。适合检索研究生并行编程课程设计、教学活动与考核设计。
