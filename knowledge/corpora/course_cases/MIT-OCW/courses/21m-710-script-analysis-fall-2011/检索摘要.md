21T.131 Script Analysis 是 Theater Arts 本科课程，涉及表演艺术、戏剧、文学、批评与戏剧文学。课程讲如何为剧场阅读剧本：细读不同时期与美学风格的剧作，分析场景建构、布景、灯光和对话如何表达故事与主题，辨明剧本给演员和导演的解释选择，并考察语言如何构建戏剧世界。课堂每周两次、每次1.5小时，无先修要求。考核含两篇论文、最终论文和最终项目；项目可为设计、场景表演、回应性原创剧本或影视改编，需课堂展示并配10-15页论文，可合作但合作者各交论文。缺席超两次影响成绩，阅读须提前完成，论文须按时提交且可能需修改。适合本科戏剧、表演艺术及文学与批评等剧本细读、讨论与项目制考核需求。
