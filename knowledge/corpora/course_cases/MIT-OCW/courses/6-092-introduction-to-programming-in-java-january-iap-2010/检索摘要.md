6.092《Java编程入门》（Introduction to Programming in Java）是MIT EECS 2010年1月IAP本科课程，主题为计算机科学、编程语言、软件设计与工程。课程用Java介绍软件工程，覆盖对6.005有用的概念，讲授Java基础，重点开发高质量、可运行、解决真实问题的软件。适合有编程经验者，零基础但有动力也可；已修6.005者不应选。教学为每周2次1小时讲座和2次1小时辅助实验，共4周。讲义和编程作业有GravityCalculator、FooCorporation、Marathon、Library、Graphics!、Magic squares等。
