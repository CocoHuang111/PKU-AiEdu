6.006 Introduction to Algorithms（算法导论，Spring 2020，EECS 本科）介绍计算问题的数学建模、常见算法、算法范式与数据结构，含动态数组、堆、平衡二叉搜索树、哈希表，排序、图搜索、动态规划；强调算法与编程关系、性能度量与分析。适合本科算法入门、数据结构与算法、计算建模、算法编程结合。每周两次讲座、两次复习课，每次1小时。先修：6.0001 Python 3 编程与 6.042J 离散数学（集合、逻辑、组合、证明、递归、数论、图论、概率）。作业为 Problem Sets，Problem Set 0 评估先修并按字母等级，C或以下需与教职员会面。附讲座笔记、视频、考试与解答。
