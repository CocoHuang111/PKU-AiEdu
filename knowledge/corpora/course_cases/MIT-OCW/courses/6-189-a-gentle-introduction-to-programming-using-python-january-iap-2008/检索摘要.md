6.189《A Gentle Introduction to Programming Using Python》是MIT电气工程与计算机科学系2008年IAP本科课程，面向有强烈学习动机、几无编程经验的学生。课程用Python入门，重点为规划和组织程序、Python语法；讲座互动，含课堂练习。主题覆盖变量与类型、函数与递归、控制流、字符串与列表、Python模块与调试、字典和列表推导式。项目一Hangman用增量编程拆分任务；项目二Guitar Hero克隆强调模块化和团队合作。作业与评价含课堂实验、问题集、编程作业、项目和测验，适合检索Python编程入门、互动教学、项目、团队合作等教学需求。
