## Assignments

This page presents the assignments, along with supporting MATLAB<sup>®</sup> templates, datafiles and “Grade-o-Matic” files. Grade-o-Matic software files are codes that allow you to determine if your code is working, and your grade for each question. More information about Grade-o-Matic files can be found in [Assignment 1 (PDF - 1.4MB)](https://ocw.mit.edu/courses/2-086-numerical-computation-for-mechanical-engineers-spring-2013/resources/mit2_086s13_assignment1/).
