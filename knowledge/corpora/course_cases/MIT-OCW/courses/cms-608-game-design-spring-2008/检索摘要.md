CMS.608《Game Design》是 Comparative Media Studies/Writing 本科课，2008春开，主题为 Game Design 与 Media Studies，每周讲座两次、Lab 一次。课程历史性考察游戏与游戏机制演变，涵盖运动、游戏节目、机会、校园、棋盘、角色扮演和数字游戏，提供分析比较游戏设计的工具与历史语境；学生团队设计、修改并充分测试游戏，以理解规则互动与演变。考核：参与15%、个人论文35%、团队项目50%；论文研究百年历史游戏或设计经典 clubhouse game 变体，团队改编非棋盘游戏并设计原创游戏。适合游戏史、机制分析、playtesting 与团队项目教学。
