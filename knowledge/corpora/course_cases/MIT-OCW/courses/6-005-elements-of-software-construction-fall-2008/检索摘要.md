6.005 Elements of Software Construction（软件构造要素）是 2008 年秋 EECS 本科课，属计算机科学、编程语言与软件工程。课程讲授软件开发原则与技术：用抽象捕捉问题本质，涵盖状态机、函数式编程、面向对象编程，用设计模式连接模型与代码，以接口和规约实现模块化与解耦，用不变式推理代码，并涉及测试、测试用例生成、覆盖率。上课为每周两次 1.5 小时讲座，用 Java 开发中小型系统，练习建模、设计、实现与推理。作业含三次探索、三次问题集和项目；成绩为探索 20%、问题集 30%、项目 40%，其余 10% 依复习课参与和实验评定。适合本科软件构造、软件设计、Java 编程和软件工程教学检索。
