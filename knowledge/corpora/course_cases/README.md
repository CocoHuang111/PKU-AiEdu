# 国外公开课程案例库

本目录保存完整课程层面的公开资料，服务于相似课程匹配、大纲设计和教学设计。英文正文不翻译、不改写，中文检索摘要单独保存。

## 当前内容

| 来源 | 课程数 | 英文页面 | 版本 |
| --- | ---: | ---: | --- |
| `MIT-OCW/` | 2587 | 14663 | MIT OCW 各公开课程版本 |
| `Yale-OYC/` | 40 | 1100 | Open Yale Courses 公开课程与课次 |

当前共保存 **2627 个课程/课程版本、15763 份英文页面和 2627 份课程级中文检索摘要**。当前目录不包含 Harvard、Stanford 或 CMU 课程材料。

## 文件结构

每门课程包含 `course.yaml`、`resources.jsonl`、**唯一一份课程级 `检索摘要.md`**，以及实际公开且成功提取的英文页面 Markdown。页面文件只保留来源信息和英文原文，不再重复写页级检索摘要。各来源的具体字段和已知限制见其目录说明。

视频、图片和二进制附件不下载，只保留来源链接。少数只有客户端动态内容的空壳页标为 `skipped`，URL 仍保留在 `resources.jsonl`。向量库按课程只保存一条中文摘要索引；命中后从本目录读取课程说明、大纲、日历、作业和考试等完整课程级材料。
