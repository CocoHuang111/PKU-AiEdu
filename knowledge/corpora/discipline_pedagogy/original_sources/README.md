# 原文来源归档

本目录集中保存 `literature_reviews/` 使用或曾用于前期院系整理的全部本地原始资料。网页和PDF保持下载时的原始字节；各子目录的 `manifest.tsv`、`download_status.tsv` 与 `SHA256SUMS` 用于核对来源、归档状态和文件完整性。

## 目录

- `literature_review_sources/`：第二批文献综述优先归档的7份开放网页原文。
- `legacy_external_sources/`：前期逐院系整理收集的11份专业学会、认证机构、国家科学院、政府和高校教学资源原文；另有16项只能保留链接，详见该目录的清单。
- `pku_official_snapshots/`：30份北京大学院系或培养方向官方网页/PDF快照，只用于核对院系方向和校内语境，不作为通用教学法有效性的证据。

- `medical_health_sources/`：医学大类六个子类综述使用的22份官方网页、专业标准与研究原文，包括六学院官网快照。

## 使用边界

1. 本地保存网页不等于取得再次发布权；知识库正文只做必要概括并标注出处。
2. 拒绝抓取、超时、返回空壳页面或受限制的来源不伪造“原文”，只在清单中保留官方链接和状态。
3. 北京大学官方快照用于核对院系与培养方向，不据此推断该院系已经实施某种教学方法。
4. 四个子目录分别保存原有清单和校验值，迁移时未改写原文文件。
