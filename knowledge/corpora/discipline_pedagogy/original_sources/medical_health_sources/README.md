# 医学与健康教育原文归档

本目录保存医学大类六个子类综述所使用且可正常公开抓取的22份原始网页或PDF。文件保持下载时的原始字节，不对正文、版式或链接作改写。

## 覆盖范围

- 共通医学教育：胜任力本位教育、全民健康覆盖能力、世界医学教育质量标准、跨专业协作、模拟教学、团队式学习及国内医教改革。
- 六个子类：基础医学、药学、公共卫生、护理、医学人文、医学继续教育。
- 北京大学官方快照：六个学院各1份，用于确认培养定位和校内语境。

## 文件与校验

- manifest.tsv：逐项记录机构、题名、来源网址、本地文件、格式和主要用途。
- SHA256SUMS：22份原文文件的SHA-256校验值。
- PDF已用 pdfinfo 与 pdftotext 检查可读性，并抽查首页渲染；网页已检查存在可解析正文。

## 边界

1. 本地归档不等于取得再次发布权；知识库正文只做必要概括并标注出处。
2. 北京大学官网材料用于说明学院定位，不据此声称具体教学法已经实施或有效。
3. 超时、TLS证书不匹配、空响应或损坏PDF不收入目录，也不伪造原文。
4. 部分标准网页会持续更新；manifest记录的是2026-09-22检索时的官方入口，本地文件为当日快照。

**归档日期**：2026-09-22。
