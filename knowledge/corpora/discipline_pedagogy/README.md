# 三十院系与医学扩展学科教育文献综述

## 文件划分

- `01-STEM十院系教育文献扩充.md`：数学科学学院至环境科学与工程学院。
- `02-人文社科十三院系教育文献扩充.md`：中国语言文学系至新闻与传播学院。
- `03-经管与交叉七院系教育文献扩充.md`：经济学院至汇丰商学院。
- `04-三十院系与医学九大学科门类汇总.md`：将原30个方向归入八类，并增加医学第九大类；同时合并国内改革反思、方法补充和重点政策与研究资料。
- `05-医学大类六学院教育文献综述.md`：将医学作为第九大类，按基础医学院、药学院、公共卫生学院、护理学院、医学人文学院、医学继续教育学院六个子类整理学科特点、教学方法和评价证据。

前三份逐院系综述共含30个院系章节、120条重点文献记录，去重后对应105个可追溯网址或DOI。每个院系章节均单列“学科教育特点”，说明该学科如何生产知识、什么构成证据、学生常见困难及适合的评价对象。

## 选材标准

1. 优先专业协会、认证机构、国家科学院和政府教学标准。
2. 研究论文优先系统综述、元分析、多机构研究或有清晰研究设计的实证研究。
3. 专业标准用于说明能力与课程要求；实证研究用于判断特定方法在何种条件下可能有效，二者不混为一谈。
4. 单课程、单机构研究不概括成普遍因果结论；正文使用“研究显示”“建议”“可采用”等有限表述。
5. 每个院系均补充学科教育特点、文献支持的教学知识、可实施方法和至少四项新增或重点文献。
6. 原30个院系方向的八大类与新增医学大类均为知识库检索分类，不代替北京大学官方学部划分；医学大类内部严格采用本稿确认的六学院结构。
7. 国内政策文件用于说明改革目标，反思性研究用于识别风险；二者均不直接当作特定教学方法有效的因果证据。

## 与原 01—08 通用稿的关系

原 01—08 通用学科教学稿已不再作为独立语料保留。其中与30个院系重合且有明确教学价值的部分，经去重和证据对照后已合并到 01—03 的相应院系，包括概念—表征—程序区分、物理建模循环、非菜谱式实验、调试闭环、过程可追踪评价、四遍史料阅读、结构化争议与语言任务循环。原 08 医学与健康教育稿中可取的通用内容已在补充新文献、校正院系范围后并入 05；医学严格按六学院展开。两份北京大学培养方案只用于确认原30个院系方向，不作为医学教学法来源。
