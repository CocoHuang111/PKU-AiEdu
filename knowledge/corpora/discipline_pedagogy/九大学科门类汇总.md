# 九大学科门类教学特点与知识综述汇总

本稿把原30个院系方向压缩为八个便于检索的大类，并把医学作为第九个扩展大类；医学内部按基础医学院、药学院、公共卫生学院、护理学院、医学人文学院、医学继续教育学院六个子类组织。分类服务于教学知识组织，**不是北京大学官方学部或院系分类**。培养方案只用于确认原30个方向；医学六学院范围依北京大学医学部院系设置另行确认。以下学科教育特点和方法均由所列专业组织、研究综述、教育标准与研究报告综合整理。

## 二、理科

### 覆盖方向

01 数学、02 物理、03 化学、04 生命科学、05 地球与空间科学、06 城市与环境、07 心理与认知科学。

### 学科教育特点

- 理科不是统一的“公式—实验”模式。数学主要以定义、公理、证明和反例建立必然关系；物理在理想化模型、数学表征和实验现象之间往返；化学连接宏观现象、微观结构和符号表征；生命、地球、环境与心理科学则更多处理变异、历史过程、复杂系统、测量误差与概率推断。[1][2][3][4]
- 共同难点是学生能执行程序却不能解释概念，把图、式、模型、实验现象和真实系统彼此割裂；在经验科学中，还容易混淆相关、机制与因果，忽略尺度、样本和不确定性。[2][3][4]
- 因此，理科评价不能只看最终数值。应观察学生能否提出问题、选择表示、说明假设、生成或分析证据、比较模型、处理误差并界定结论适用范围。[1][3][4]

### 核心教学知识与方法

1. 先诊断直觉与先备概念，再用预测—观察—解释、概念投票或反例制造可讨论的认知冲突。
2. 要求学生在文字、图像、公式、模型、数据和实物现象间转换，并解释每种表示保留或舍弃了什么。
3. 实验课围绕问题、测量、误差、证据和修订组织；物理建模可用“系统边界—理想化—变量关系—可检验预测—证据—模型修订”链条外显，不以验证教师已知答案的“菜谱实验”替代探究。
4. 把真实但经过支架化的数据、野外材料或研究片段引入课程，让学生练习从不完整证据作有限推断。
5. 使用累计检索、低风险形成性评价、研究记录和口头解释，分别检查知识保持、过程判断和个人理解。

### 国内改革反思与方法补充

- 基础学科拔尖学生培养计划2.0强调使命驱动、大师引领、创新学习、科教融合和国际合作；基础学科“101计划”进一步把改革落到核心课程、教材、教师团队和实践项目等基础要素。[国内7][国内8]
- 这些政策说明基础学科改革不能只增加科研经历。若学生尚不能解释核心概念、证据标准和模型边界，过早进入碎片化课题可能形成“参与科研但没有形成学科结构”的假象。
- 中美学生物理学习的跨文化研究发现，严格内容训练与一般科学推理能力不能简单画等号，提示课程需直接教授假说、变量控制、模型检验和证据推理。[国内9]

方法上应以少量核心概念与学科实践重构课程递进；低年级先分析经过裁剪的真实数据和论文片段，中高年级再承担开放研究；研究日志和答辩用于检查个人理解。地球、环境、生命和心理课程可以使用中国本地数据与情境，但仍须保持采样、测量、伦理和因果推断标准。

## 三、工科与信息

### 覆盖方向

08 信息科学技术、09 工程、10 环境科学与工程。

### 学科教育特点

- 计算与工程知识的共同核心是把需求转换成可实现的抽象、算法、结构或系统，并在约束下通过建造、测试、失败和迭代检验设计；“能运行”不自动等于正确、安全、公平或可维护。[1][2]
- 工程问题通常没有唯一最优答案，学生必须在性能、成本、安全、环境、伦理和利益相关者需求间权衡。环境工程还需把自然过程、技术设施、治理规则和长期风险视为耦合系统。[2][3]
- 适合的评价对象是完整设计过程：需求、假设、方案比较、代码或原型、测试证据、失效分析、版本变化、团队贡献和公开说明，而不只是成品演示。[1][2][3]

### 核心教学知识与方法

1. 用分层项目把问题定义、设计、实现、验证和反思连接起来，并设置阶段评审而非只在期末验收。
2. 计算课程并列训练代码阅读、算法解释、调试、测试与独立编写；调试按“复现—缩小—假设—诊断—修复—回归”形成闭环，并用口头答辩、版本记录和新情境任务确认个人理解。
3. 工程设计先明确使用者、约束和验收标准，再比较多个方案；把失败模式和安全余量作为正面学习内容。
4. 环境问题使用系统图、物质流/能量流、情景与敏感性分析，显式表达尺度、反馈、延迟和不确定性。
5. 团队项目同时设置共同产物与个人证据，避免把协作表现误作每名学生都已掌握。

### 国内改革反思与方法补充

- 新工科政策强调从教育思想、质量标准、技术方法和育人模式等方面改革，并加强产教融合与跨学科培养。[国内10]
- 国内工科教育研究区分工科知识、工程实践与技术教育，主张工科教育和工程教育一体化，同时指出政府发动改革后，高校仍应承担人才培养主体责任。[国内11]
- 产业参与不能等同于用企业工具、短期岗位技能或竞赛项目替代数理基础、系统思维、工程伦理和独立验证；真实项目也要防止企业交付目标压过学生学习目标。

校企项目宜同时配置校内教师和实践导师：企业提供真实情境与约束，学校负责概念深度、评价公平和个人学习证据。评价除功能实现外，还应覆盖需求证据、备选方案、验收测试、失效分析、鲁棒性、安全、隐私、可维护性、环境影响和公共责任。

## 四、人文

### 覆盖方向

11 中国语言文学、12 历史、13 考古文博、14 哲学（宗教学）。

### 学科教育特点

- 人文学科以文本、语言事实、档案、器物、遗址和思想论证为材料，通过细读、来源批判、语境化、互证、概念分析和解释竞争形成知识。解释可以开放，但不能脱离材料与推理。[1][2][3]
- 学生容易把阅读感受或个人立场当作充分论证，把史料当作透明事实，混淆观察与解释，或只总结权威观点而不重构其论证。[1][2][3]
- 教学评价应关注材料选择与出处、证据权重、语境、论证结构、替代解释、伦理和修订过程。长论文宜拆成研究问题、材料卡、论证图、初稿和回应反馈等可观察阶段。[1][3][4]

### 核心教学知识与方法

1. 教师示范专家如何批注、提问、定位关键词、判断来源并从局部材料形成有限解释；史料阅读可按“来源与语境—整体主张—关键证据—回评视角与可信度”四遍递进。
2. 让相互冲突的文本、史料、版本或物证进入同一任务，要求学生说明为何赋予不同证据不同权重。
3. 用论证图和反例训练区分主张、前提、中间结论与反驳，再转换为连贯写作。
4. 考古与文博教学把观察、记录、推断和伦理分栏；田野、收藏和展示决策均保留出处与责任链。
5. 采用多轮写作、同伴反馈和修订说明，使评价能够看见解释如何因证据而改变。

### 国内改革反思与方法补充

- 新文科建设提出发现新材料、新问题和新观点，形成具有中国主体性的理论、学科与教学体系。[国内12]
- 反思性研究指出，新文科实践可能出现定位不清、跟风模仿和路径依赖；对17个典型经验的跨案例研究还提示专业特质淡化、文科知识价值稀释和技术替代等风险。[国内13][国内14]
- 因而数字工具和跨学科项目只有在加强文本、语言、史料、物证和论证训练时才构成改进；把可视化、数据库或生成结果本身当作成果，会掩盖材料选择和解释过程。

课程应先建立细读、版本、来源批判、田野记录和论证重构等基本功，再用数字工具扩大材料规模。数字项目须提交语料来源、缺失数据、分类规则和算法限制；跨学科合作还应明确人文学科贡献的是概念、语境、意义解释、价值判断还是材料方法，防止只承担“包装与传播”。

## 五、语言教育

### 覆盖方向

15 外国语、29 对外汉语教育。

### 学科教育特点

- 语言能力不是孤立规则的总和，而是在特定对象、目的、体裁和文化语境中理解、协商并表达意义的能力。ACTFL以功能与任务、准确性、语境与内容、文本类型描述实际表现。[1]
- 第二语言发展并非线性累加。学习者可能知道规则却无法实时使用，且流利度、准确度、复杂度与得体性会随任务条件产生权衡。汉语教学还需统整声调、汉字、词汇语法、语篇与文化语用。[2][3]
- 评价应依据真实或近真实表现，跨听说读写与多个时间点收集证据；离散词汇语法测验可以诊断局部知识，但不能替代沟通能力评价。[1][2]

### 核心教学知识与方法

1. 先规定现实沟通结果、受众和信息差，再倒推输入、语言支架与成功标准。
2. 使用“可理解输入—意义协商—产出—聚焦形式的反馈—重做”任务循环。
3. 同一主题跨听说读写迁移，逐步增加文本长度、即兴程度、受众差异和文化含义。
4. 汉字教学连接形、音、义、词汇和真实文本，避免机械抄写成为唯一学习活动。
5. 采用分析性量表、表现样本、学习者自评和作品档案，观察能力随时间的变化。

### 国内改革反思与方法补充

- 《大学英语教学指南（2020版）》围绕课程定位、目标、课程设置、评价、方法和资源提出分类指导；国内相关研讨还讨论了形成性评价、混合教学和学术英语实践。[国内15]
- 新文科语境要求外语教育兼顾语言能力、区域国别、跨文化阐释和国际传播；对外汉语教育还须处理汉语特点、学习者母语差异与真实中国语境。
- 改革风险包括把平台使用量当作自主学习，把文化教学变成事实清单，或只追求易测的词汇语法而缩减真实理解和表达。

教学可按学生起点与专业需要设置分层目标，以实际表现而非统一教材进度判断达成；外语课程可与历史、国际关系、法律、新闻和科技共建真实任务，但仍需评价语篇、语用、准确性和跨文化适切性。数字练习数据只宜作诊断，高风险评价应保留可核验的听说读写表现。

## 六、艺术

### 覆盖方向

16 艺术。

### 学科教育特点

- 艺术知识由感知、材料、技法、创作实验、作品阐释和文化语境共同构成；开放性不表示任意，专业判断仍需借助可讨论的形式、概念和语境证据。[1]
- 工作室学习依赖示范、制作、讲评和反复修改，但质量标准可能隐而不宣，讲评中的权力关系也可能抑制探索。学生还需学习如何描述作品、提出问题并把反馈转化为决定。[1][2]
- 成品不能充分代表学习。过程作品集应保留研究、草图、材料实验、失败分支、反馈与修订理由；评价可区分概念发展、形式技法、实验风险、反思和呈现。[2][3]

### 核心教学知识与方法

1. 通过教师示范和范例比较外显材料选择、构图、叙事与修改中的专业判断，但不把范例变成复制模板。
2. 将讲评分为描述、提问、解释、建议和作者回应，先训练反馈语言，再将其用于形成性改进。
3. 设立阶段性工作室检查点，允许失败分支进入作品集，并要求学生解释保留或放弃方案的依据。
4. 将同伴、教师、自评和公开呈现结合，避免单一评审者的偏好成为唯一标准。

- 文化传承也不等于复制传统形式；学生应理解材料、技法与历史语境，再通过创作完成有依据的转化。

作品集应保存观察、研究、草图、材料实验、失败、讲评和修改，降低一次比赛或最终展演对成绩的支配。博物馆、非遗、社区和当代艺术现场应转化为有问题、有材料、有创作回应的任务。使用数字生成工具时须披露素材与过程，评价仍聚焦选择、判断、修订、作者责任和文化语境。

### 学科教育特点

2. 用调查、访谈、档案、统计、法律权威和信息来源的组合任务训练证据三角互证，要求报告材料边界。
3. 模拟或结构化争议前提交共同事实与证据底稿，过程中记录决定并交换立场，结束后用理论与规则复盘；满意度和参与度不能替代学习证据。
4. 使用判例摘要、政策备忘录、检索日志、研究报告和新闻作品等真实体裁，并提供低风险形成性反馈。
5. 评价显式纳入伦理、程序公平、隐私、分配影响、公共价值、来源透明和更正能力。

## 九、跨学科与教育

### 覆盖方向

27 元培、28 教育。

### 学科教育特点

- 跨学科教育的核心不是“多选几门课”，而是理解不同学科如何提问、使用概念、认可证据和形成结论，再围绕共同问题整合贡献并说明不可通约之处。[1]
- 教育学本身也是多方法领域，需要在学习理论、实验和准实验、测量、调查、质性材料、政策制度和设计实践之间作证据判断。[2][3]
- 共同难点是广而不深、术语并置、方法与问题错配，以及把技术或方案的新颖性当作效果。评价应同时检查学科基础、整合理由、研究质量、情境与伦理、迭代及反思。[1][2][3]

### 核心教学知识与方法

1. 项目开始时建立“学科贡献矩阵”，列明每一学科的问题、概念、方法、证据、尺度和局限。
2. 保留学科基础课与导师制，用阶段里程碑防止开放选择变成缺少结构的课程集合。
3. 对同一教育问题设计多种研究方案，比较因果效度、生态效度、外部效度、伦理和资源代价。
4. 设计型项目按需求—理论—原型—实施证据—迭代运行，要求说明每次改变由什么证据触发。
5. 对生成式AI等工具要求披露使用过程并人工核验，检查隐私、偏差、可访问性和是否替代了目标学习活动。[4]

跨学科项目应先建立各学科的核心概念、方法和证据门槛，再界定共同问题；不同学科教师对中间产物联合评审，要求学生回应标准冲突。教育改革项目采用“问题诊断—理论机制—设计—实施证据—结果—迭代”的记录结构，没有对照条件时避免强因果宣称，并保留无效或失败案例以区分理论、实施、评价和情境问题。

## 十一、跨类别共通原则

1. **先确定知识与证据，再选择活动。** 讨论、项目、实验或模拟本身不是目的；任务必须让学生实际执行本学科的提问、证据判断和表达。
2. **把专家隐性过程外显。** 示范如何读材料、选择表示、判断来源、排除方案、处理错误和修订结论。
3. **形成性评价必须可改变后续学习。** 在高风险成品前安排低风险尝试、反馈和重做，并保存过程证据。
4. **真实任务需要支架。** 初学者面对未经分解的完整专业任务容易超载；应逐步增加材料规模、开放度、受众差异和不确定性。
5. **区分“参与”“满意”与“学习”。** 评价应直接观察知识、推理、作品或表现，并与课程目标对齐。
6. **对方法效果保持边界意识。** 专业标准说明“应培养什么”，单课程研究只能说明特定条件下的结果；任何方法都需用本地学生作品与学习数据继续验证。

## 十二、国内改革文献带来的四项校正

国内本科教育质量报告曾指出教学模式单一、教学方法相对落后以及专业课小班教学覆盖有限等问题；对70年本科教学改革政策的梳理则把学习者中心、课程教材教法数字一体化和质量评价视为后续改革方向。[国内1][国内6] 结合九类学科文献，可作以下校正：

1. **课程改革不能用“采用新形式”自证有效。** 国内一流本科课程文件明确反对信息技术应用的简单化、形式化；评价应回到学生是否完成更高阶的学科任务以及能否迁移。[国内2][国内3]
2. **科教融合和产教融合不能挤压基础。** 基础学科“101计划”强调核心课程、教材、教师和实践项目协同；新工科反思则要求区分工科知识、工程实践和短期工具技能。[国内8][国内11]
3. **交叉和数字化不能稀释学科本体。** 国内新文科研究指出定位不清、跟风模仿、专业特质淡化、知识价值稀释和技术替代等风险。[国内13][国内14]
4. **评价改革要留下可检查的学习证据。** “学生中心、产出导向、持续改进”应落实为学生作品、过程修订、个人解释、学习增值和下一轮课程调整记录，而不是停留在目标表述。[国内4][国内5]

### 国内本科教学的共同实施方法

- 在期末成品前设置草案、试做、反馈和重做，保存学生如何根据证据修订的记录。
- 同时使用考试、专业作品、口头解释、过程档案和学习者反思，避免用单一分数代表复杂能力。
- 课程团队定期抽样分析学生作品，而不只比较平均分或满意度；记录发现的问题、采取的调整和下一轮结果。
- 对同一能力跨年级保存代表性任务，观察学生从规则执行到独立判断的增值。
- 采用技术前说明它支持哪一种学科认知活动、学生必须亲自完成什么、如何保存过程证据，以及教师如何核验来源、偏差和个人理解。

### 国内材料的证据边界

- 国内政策与标准主要说明改革目标、课程要求和评价方向，不能单独证明某种教学法有效。
- 理论、政策分析和批判性研究适合识别长期问题、实施风险与可能机制，但其建议仍需本地课程验证。
- 实践案例提供可迁移的设计线索；是否有效仍要依靠学生作品、课堂观察和学习结果。
- 专业标准回答“应培养什么”，实证研究才可能回答“某种方法在什么条件下产生了什么结果”，二者不混为一谈。
